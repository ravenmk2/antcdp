# HTTP 开发约定

接口以[服务端路由与处理器](../../internal/server/)、领域 DTO、[前端 API 层](../../web/src/api/)及对应测试为准。本文不复制端点列表、字段表、默认值或错误码目录。

## 编码与访问

前端通过同源 `/api/v1` 访问业务服务。JSON、时间、业务 ID、响应外壳与条件版本保持前后端一致；大整数标识通过字符串传输，不依赖 JavaScript 数字精度。

会话认证、资源授权和写操作的 CSRF 校验在服务端执行。客户端可见性和传入的身份信息不能授予权限。错误响应不得泄露不可见资源、内部异常或秘密。

## 并发与外部副作用

对象版本、集合版本和操作凭据按具体接口使用，不互换、不解析猜测，也不通过通配条件覆盖冲突。版本校验不能代替授权。

请求取消、超时和无响应不证明写操作未执行。是否支持幂等重放、如何查询结果及允许哪些重试由实际端点决定；客户端不自动重放结果未知的外部副作用。

接口和数据变更同时更新调用方与有意义的契约测试。对已有消费者的兼容要求需明确处理，不依靠文档中的旧字段清单判断支持范围。

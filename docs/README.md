## 维护原则

仅在技术选型、模块边界、跨组件约束或工作流程改变时更新说明文档；普通业务行为变化更新代码和测试，结构变化同步领域 SQL。同一规则只在一处维护，其余位置链接引用。

事件溯源、模型上下文、投影与助手前后端通讯属于核心架构，必须保留设计关系、正确性约束和源码入口。具体事件载荷、工具参数、完整端点和限额不复制到文档。

源码导航以模块和关键机制为粒度，不为每个业务模块新增介绍页。历史过程、已完成改造、未落实计划和过时说明直接删除，历史由 Git 保存。文档不规定具体 UI 布局或视觉样式。

实际环境、凭据、部署记录和验收产物保存在被忽略的本机目录；部署环境信息维护在部署技能目录。文档修改审核、提交和执行规范见 [AGENTS.md](../AGENTS.md)。文档引用和 SQL 阅读副本通过审核维护，不加入 CI 或检查脚本。

## 维护约定

- 业务规则只在所属领域文档维护；公共 API 约定在 api.md，模块端点在模块文档，避免重复抄写。
- 文档描述当前行为；未实现功能集中列为限制或扩展边界，不保留已被替代的请求格式、迁移方案、原型过程和实施步骤。
- 产品中的审计、修订、创建记录、冻结清单等历史数据是有效业务能力，不属于应清理的文档过程记录。
- 纯视觉调整更新 UI 规范；权限、接口、存储变化更新对应契约。入口增删或职责变化同步本页与 [AGENTS.md](../AGENTS.md)。
- SQL 阅读副本与实际迁移保持一致，不导入现有数据库。测试跳过、静态检查、受控服务模拟和真实供应商联调分别说明。
- 原型、截图、运行日志、凭据和环境专属记录不纳入 Git；文档不依赖这些临时产物才能理解现行契约。

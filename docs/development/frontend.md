# 前端实现与维护

前端是嵌入 Go 二进制的 React SPA，从根路径加载，通过同源 `/api/v1` 使用会话、CSRF 与权限接口。本文维护技术栈、代码组织和开发方法；业务字段与状态以所属模块实现和测试为准。

## 技术栈与目录

当前技术栈为 React 19、TypeScript 7、Vite、Tailwind CSS 4、React Router、TanStack Query、TanStack Table、Base UI、Lucide 与 Zod。Markdown、代码编辑、高亮与图形相关依赖以 `web/package.json` 和锁文件为准。源自 shadcn/ui 的本地组件保留来源与 MIT 许可。

TypeScript 7 的原生编译器通过 `@typescript/native` 提供 `tsc`。由于 TypeScript 7.0 不提供旧编译器 API，`typescript` 别名使用 `@typescript/typescript6`，供 typescript-eslint 调用；业务源码始终通过 TS 7 strict 检查。两个编译器的版本均锁定在 `web/package-lock.json`。

```text
web/src/
├── api/                 # 同源请求、CSRF、响应和结构化错误
├── app/                 # 公共入口、身份与跨区域服务、路由装配
├── areas/               # console、workspace、account 区域代码
├── components/          # 基础与平台组件
├── domain/              # 共享校验、纯业务判断和服务目录
├── features/            # 共享业务能力与领域代码
├── hooks/               # React hooks
├── lib/                 # 路由、时间和通用辅助函数
├── styles/              # 样式资源
└── types/               # 与服务端 DTO 对应的前端类型
```

静态资源位于 `web/public`。第三方资源随包分发时保留来源与许可。当前字体由 `scripts/prepare-fonts.mjs` 在构建时下载、校验并准备，运行时由本站提供；内容哈希命名的字体资源使用 HTTP 强缓存。

## 路由与访问边界

路由注册、`lib/routes.ts` 的业务路径守卫、构建路由清单及其测试共同维护可访问路径，不在开发文档复制完整路由表。路径变更同步维护登录返回与旧 URL 兼容。

History Router 使用真实字符串 ID。登录返回只接受受支持的同源业务路径，拒绝外部地址、反斜杠和控制字符；已有兼容入口保留查询与片段语义。

服务端逐次鉴权。区域、资源归属、管理员能力及 API 基址由调用方显式传入，不能通过 URL 前缀或同名 ID 猜测权限。切换账号或上下文时清理不再获准访问的数据缓存。

## 请求与缓存

`api/client.ts` 统一同源 fetch、CSRF、JSON/multipart、响应外壳、版本头和结构化错误。写请求按接口要求附带条件版本、幂等或确认信息，不能假定所有模块使用同一机制。身份状态改变后同步客户端令牌状态。

TanStack Query 的 Key 包含归属、资源 ID、筛选和分页，管理取消与缓存失效；GET 仅有限重试，Mutation 不自动重试。旧请求不得覆盖新对象的结果。

认证失败、强制改密、服务不可用、安装状态及数据库异常按接口契约区分。请求取消不证明远端操作已取消或达到终态。

## 版本与恢复语义

对象版本、集合版本、作用域令牌、预览摘要和操作凭据按各自接口传递，不互换、不猜测。通用原则见[HTTP 开发约定](../api/conventions.md)，具体状态码、字段错误及重试条件查对应处理器和测试。

网络中断、无有效响应等写入不确定性保留 uncertain 状态，通过对象、列表或契约提供的操作记录核实。没有结果记录不自动等于未执行，不用存在标记确认新秘密内容，也不自动重放写入。

## 组件与领域边界

控制台、工作区和个人中心分别维护区域代码。区域不得相互导入，共享层不得反向依赖区域；跨区域访问使用公共 URL 契约。共享业务能力保留在 `features/`。

身份、查询缓存和按用户隔离的智能体运行状态位于区域共同祖先；切换区域不重建这些服务。控制台代码在管理员守卫通过后才加载。

公共基础组件不请求业务 API 或推断权限。领域组件维护数据获取、权限、字段转换和状态机。共享业务能力通过显式参数接收请求范围与授权信息，不根据业务名称相似合并领域请求或授权。

服务端目录提供的类型、默认值和参数约束按响应使用。未知字段按契约保留或拒绝写入，不能静默删减。

## 数据与内容安全

Zod 承担共享字段规则及响应边界。业务 ID 使用字符串，密码按契约分别校验 Unicode 码点和 UTF-8 字节。秘密不进入 URL、本地持久存储、日志或普通详情响应。

Markdown 禁用原始 HTML 与未经允许的远程图片。图形使用严格安全模式并清理 SVG。文件上传、绑定和删除遵循对应资源契约，上传成功不等于对象已保存；临时资源由调用方管理。

## 开发、检查与发布

支持的运行时与依赖以 `web/package.json`、锁文件和 CI 为准。启动及热更新方法见[本地开发](getting-started.md)，统一检查命令与测试方法见[测试与验证](testing.md)。不在多篇文档维护同一命令清单。

构建通过锁文件安装依赖，检查 TypeScript 并生成 `web/dist`；`scripts/verify-web.mjs` 检查根入口、路由清单、资源与图标。Go embed 嵌入构建产物，运行容器不依赖 Node 或前端源码。三条 CI 流程通过公共 [前端构建 action](../../.github/actions/build-web/action.yml) 独立执行构建，不跨流程消费产物；各自的检查范围见[测试与验证](testing.md)。产物对应本次运行的源码状态，不能用旧产物的通过记录证明新代码。

静态、模拟、实库、真实服务与浏览器检查结果分别报告，未执行项明确说明。实际环境连接、运行配置及部署记录保存在被 Git 忽略的本机配置或部署技能目录。

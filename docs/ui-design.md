# UI 设计规范

## 规范的适用方式

后续开发不要生搬硬套旧原型、截图或现有页面，也不要把某次验收的像素值当成永久标准。先明确用户任务、信息优先级、真实内容长度与设备条件，再选择布局、组件和密度。

本文区分三类信息：

| 类型 | 使用方式 |
| --- | --- |
| 产品与交互约束 | 保持权限、数据真实性、业务含义、保存/取消语义、错误恢复和可访问性。用户已确认的导航、文案和操作归属按其适用页面执行，最新明确要求优先；不能以视觉优化为由暗改业务行为。 |
| 视觉默认值 | 字号、间距、圆角、阴影、宽度、列数、断点和组件组合是设计起点。可按内容和设备调整，无需仅因偏离旧像素值再次确认；优先复用语义变量并保持同类操作一致。 |
| 当前实现与历史参考 | 当前页面的布局记录用于理解现状，不强制推广到新页面。旧原型和发布截图只供参考；历史版本与验收结果见开发说明，被替代的方案不再约束开发。 |

下文的视觉尺寸均按第二类理解；产品协议中的字段上限、文件限制、权限条件及已确认的保存/搜索行为不因此放宽。品牌 LOGO 使用定稿资源。设计调整优先验证真实内容、长文本、空/错误/加载状态、浅深主题、窄屏和键盘操作，以清晰、可用和一致为验收依据，不要求与旧截图逐像素一致。

项目与团队交互规则见 [项目与团队设计](projects-and-teams.md)，页面路由、快捷方式、表单、图标裁剪与危险操作确认详见 [详细设计第 7 节](projects-and-teams-detail.md#7-具体页面与交互)。基础功能已实现，尚未覆盖的验收边界见开发说明。

工作区侧栏项目/团队标题行的加号在桌面默认隐藏，悬停标题行或键盘焦点进入时显示；触屏设备常显。隐藏不移除布局占位或 Tab 焦点，按钮须具备可访问名称，避免布局跳动。

侧栏项目/团队分组仅显示标签与已固定快捷方式，不显示“查看全部项目/团队”；完整列表入口“我的项目”“我的团队”放入底部用户菜单，与“个人设置”“控制台”（管理员可见）依次合为一组；“外观”“退出登录”合为第二组，两组之间仅保留一条分隔线，桌面与移动端一致。工作区侧栏不再单列“个人设置”。点击进入工作区的本人参与列表，控制台全局管理导航保持独立。

正式快捷方式按账号在数据库保存并跨设备共享；项目、团队分组独立进行版本校验。旧页面保存发生冲突时重新读取并提示用户重做，不静默覆盖其他设备的排序。本地 HTML 原型存储仅用于演示。

工作区与控制台分离：工作区展示本人参与的项目/团队，侧栏支持按用户固定、取消和排序快捷方式；控制台管理全部对象及创建、归档、解散。加号表示添加快捷方式，不是创建对象。详细行为见上述设计第 7 节；当前实现边界见开发说明。

更新日期：2026-10-27。AntCDP = AI Native Team Collaboration & Development Platform（AI 原生团队协作开发平台）。视觉采用 暖色中性界面；提供浅色、深色和跟随系统三种外观，LOGO 使用小圆角正方形与蚂蚁头 SVG，陶土色与暖白色随主题互换。

## 1. 设计原则与来源

- 采用暖色中性背景、轻量侧栏、低阴影面板和克制的陶土色强调。浅色与深色共享布局、信息层级和交互；确保中文正文、表单与状态能够辨认。
- 页面围绕当前任务组织信息；顶部用于导航与返回路径，账号入口在侧栏底部。普通用户和管理员共享账号区域，管理能力集中到控制台。
- 主入口为“首页”，所有用户登录后默认进入首页。用户身份、菜单是否可见由权限决定，前端隐藏入口不代替后端授权。
- 只呈现已交付能力；项目与团队基础功能已上线，工作流、AI 执行等未交付能力不放占位菜单。

正式实现按本文的约束分级使用规范。旧版原型仅作历史交互参考，不纳入 Git 或构建依赖；正式前端使用 tokens.css 统一主题变量，Element Plus 和功能组件复用相同语义色。

## 2. 颜色

所有颜色集中在 `web/src/shared/tokens.css`。页面使用语义变量，不自行写死浅色或深色值；Element Plus 的输入、弹窗、下拉、消息、日期和表格同步映射到这套变量。

下表记录当前主题默认值。需要调整对比度或表面层次时，在语义变量层统一修改并验证双主题；不要将一页的临时色值扩散为新的全局规则。LOGO 的定稿颜色见品牌章节。

| 用途 | 浅色 | 深色 | 变量 |
| --- | --- | --- | --- |
| 页面 | `#faf9f5` | `#151515` | `--canvas` |
| 面板 / 卡片 | `#ffffff` | `#1a1a19` | `--surface` |
| 输入框 / 弹窗 | `#ffffff` | `#20201e` | `--surface-input` |
| 菜单 / 浮层 | `#ffffff` | `#2c2c2a` | `--surface-overlay` |
| 侧栏 | `#f0eee6` | `#0b0b0a` | `--sidebar-surface` |
| 主要文字 | `#141413` | `#f5f5f5` | `--text-primary` |
| 次要文字 | `#30302e` | `#a3a3a3` | `--text-secondary` |
| 辅助文字 | `#5e5d59` | `#8a8a8a` | `--text-muted` |
| 分隔线 | `#dedcd1` | `#3d3d3a` | `--border` |
| 控件描边 | `#c2c0b6` | `#73726c` | `--border-control` |
| 主操作 / 链接 | `#141413` | `#faf9f5` | `--accent` |
| 主操作文字 | `#faf9f5` | `#141413` | `--on-accent` |
| 品牌点缀 | `#d97757` | `#d97757` | `--brand` |
| 键盘焦点 | `#154c92` | `#90c3f6` | `--focus` |
| 正常 | `#3e725b` | `#9bc5a5` | `--success` |
| 警示 | `#866020` | `#d9bc7f` | `--warning` |
| 错误 / 危险 | `#b43e3e` | `#f0a0a0` | `--danger` |

颜色和文字、图标或形状共同表达含义，不只依赖颜色。品牌展示色与正文操作色分开；浅色主操作使用墨色底、暖白文字，深色主操作使用暖白底、墨色文字。陶土色用于 LOGO 和品牌装饰，不用作常规主按钮底色。头像裁剪网格保留图像工具所需的固定白色引导线。

浅色采用暖白背景、深墨色正文与主按钮，配合中性灰阶及陶土品牌点缀。颜色与层次以本规范的语义变量为准。

深色使用五级表面：侧栏、主画布、卡片、输入框与弹窗、菜单浮层。保留中性主按钮、陶土色 LOGO 和专用功能状态色；辅助文字使用较亮的 `#8a8a8a`，确保表单说明可读。

深色分隔线与控件描边使用固定暖灰色，避免透明边框随底色变化而弱化。搜索框、输入框与选择器聚焦统一使用单层细描边及焦点语义色，不叠加外扩光晕或双层轮廓；悬停边框使用 `--border-control-hover`，减小与默认边框的反差。按钮、链接与原生选择器的键盘焦点保留 2px 轮廓，偏移 2px；强制颜色模式下输入控件保留系统色焦点轮廓。主按钮以实色背景建立层级，不额外叠加投影。深色菜单与弹窗使用控件级描边，菜单增加阴影并采用更亮的浮层底色。

主题入口在安装、登录、注册、维护页右上角；登录后收纳在用户菜单的“外观”二级菜单中。一级入口显示当前外观；桌面支持悬停或点击展开，鼠标离开入口后保留 300ms 关闭延迟，移入二级菜单时取消关闭；移动端支持点击展开。二级菜单提供浅色、深色、跟随系统三项，并以勾选标识当前选择。键盘右方向键、Enter 或空格展开二级菜单，左方向键或 Escape 返回一级；顶部导航不再单独显示主题切换。首次跟随系统；选择保存在本机 `antcdp.appearance`，允许的值为 `system`、`light`、`dark`。系统模式实时响应操作系统变化；其它浏览器标签页同步偏好变化。浏览器禁用存储时当前页面仍可切换，刷新回到系统偏好。该偏好不进入系统设置或账号数据库。

`theme-init.js` 在样式和 Vue 加载前设置根节点 `.dark` 与 `color-scheme`，避免主题闪烁；原生下拉、滚动条及 Element Plus 浮层跟随主题。主题样式覆盖自动填充、只读、禁用、错误、焦点、选中和悬停状态。系统强制颜色模式保留浏览器行为。

## 3. 中文排版

首选 MiSans，保留系统字体兜底：

```css
font-family: "MiSans", -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
```

MiSans 使用官方 WOFF2 字符分片，构建时下载并校验 SHA-256，随前端产物发布；字体二进制和缓存不提交 Git。运行时从本站按需加载，不请求第三方字体服务。采用 `font-display: swap`，加载期间或失败时使用系统字体。包含 400、450、500、600、650、700 字重；官方静态资源不含 550，因此将 550–600 映射到 600 字形。登录页注明使用 MiSans，并链接随应用发布的原始许可协议。中文使用正常字距；字重承担层级，避免大段粗体。用户名、ID、时间与技术值可使用 Cascadia Code / Consolas / monospace；数字优先等宽排列。

| 层级 | 建议大小与行高 |
| --- | --- |
| 全局正文 | 15px，1.65；段落 1.75 |
| 页面主标题 | 28px，1.4；小屏 26px |
| 区块标题 | 20px，1.5；设置小节 16px |
| 页面说明 | 15px；小屏 14px |
| 导航 | 15px |
| 表单 label / 输入 / 按钮 | 14px；输入行高 1.5，按钮 1.45 |
| 表格内容 / 用户主行 | 14px，约 1.5–1.55 |
| 表头、提示、状态和用户次行 | 13px，提示行高 1.75 |
| 数量与统计 | 29px，1.2；小屏约 27px |
| 登录表单标题 | 30px；小屏 29px |
| 页脚与次要标识 | 通常 13px；侧栏用户名和计数可用 12px |

新增主要内容不以 12px 承载。长中文提示允许自然换行；用户名可截断并提供完整值，密码与错误详情不能为了布局静默截断。

## 4. 布局与导航

以下几何值为现有布局的参考默认值，按内容宽度与空间利用率调整；导航的入口含义和访问权限保持一致。

| 区域 | 参考默认值 |
| --- | --- |
| 桌面侧栏 | 固定左侧，宽 240px，视口高 100dvh；1200px 以下桌面宽 224px |
| 折叠侧栏 | 宽 76px，保留图标、头像及可访问名称 |
| 顶部导航 | 高 72px，吸顶；面包屑和返回路径，不放桌面账号菜单 |
| 主内容 | 最大宽 1600px，桌面内边距 32px |
| 账号入口 | 侧栏底部，头像、显示名称、用户名；顶部仅保留一条细分隔线，入口不加外框或身份徽章，仅悬停和展开菜单时显示柔和底色；菜单向上展开并自动避让 |
| 面板 | 使用主题面板色、细分隔边界和适量圆角；当前常用 12px 圆角、18–26px 间隔 |
| 常规弹窗 | 宽 560px，小弹窗 460px；内容可滚动 |
| 头像裁剪 | 宽 650px，图像操作区和预览区分列 |

已有顶部导航的首页、个人设置、概览、用户管理、系统设置和审计日志，不再重复展示内容区页面大标题及说明；主内容保留可访问名称。系统设置日常不显示重新加载按钮，加载或保存失败时提供重试或重新加载入口；其他页面操作使用紧凑右对齐操作行，业务区块标题保持。刷新使用 Lucide `RotateCw` 单箭头圆环，只有主动点击刷新按钮才启动动画；首次进入、浏览器刷新和筛选查询不启动旋转，加载期间仍禁用重复点击。点击后动画至少持续 600ms，避免快速响应时看不清，数据不等待动画即可更新，长请求结束后停止；刷新图标按产品要求不受减少动态效果模式影响，其他动效仍遵循系统设置。审计页底部不再展示只读与敏感内容说明。

当前系统级导航与页面安排（导航含义及用户确认的入口归属继续执行，具体视觉组织按任务优化）：

- 工作区侧栏：`首页`，随后为项目、团队固定项分组。分组标题使用 12px 弱化文字，固定项图标统一为 19px，与首页文字起点对齐；组内紧凑、组间留白，不增加分隔线。空分组显示“尚未固定”。
- 控制台：`系统概览`、`项目管理`、`团队管理`、`用户管理`、`服务集成`、`系统设置`、`审计日志`，按此顺序排列。
- 账号菜单：第一组为我的项目、我的团队、个人设置、控制台（管理员可见）；第二组为外观、退出登录。使用 Element Plus Dropdown 组件；外观为嵌套子菜单。控制台顶部提供“返回工作区”。
- 不显示“个人空间”、侧栏系统信息卡或运行状态卡；运行信息仅放系统设置的相应页面。
- 用户管理页保留状态页签及数量、搜索筛选、用户表格和分页；添加用户放在查询工具栏右侧，不单独占行；不显示标题说明、四个统计卡片、列表下方权限说明或查询栏管理员提示。
- “原型导航”、演示身份切换、数据重置与 LOGO 实验室属于原型工具，不进入正式产品导航。
- 控制台概览直接展示四个账号指标，以及“最近操作 + 常用操作 / 访问策略”的主次分栏。不展示系统名称、更新时间与刷新按钮整行，加载失败时保留重试入口。指标包括全部、正常、禁用账号和管理员（含创始人）；前三项跳转到对应用户筛选，管理员仅展示数量，避免与排除创始人的身份筛选口径混淆。
- 最近操作显示真实最近五条记录，整行可打开审计详情，标题栏保留紧凑“查看全部”链接。常用操作提供添加用户、注册与会话、系统信息；访问策略显示注册状态、会话闲置有效期和系统时区，不展示没有检测依据的健康状态或占位功能。
- 概览指标卡使用 OverviewMetric，区块使用 OverviewSection；指标与快捷操作由类型化数组配置，主体网格容纳后续真实业务模块，不预建插件机制或未来模块空卡。1050px 以下主体改单列、指标两列；600px 以下侧边区块纵排。首次加载展示加载态；刷新失败保留最近成功数据并注明更新时间，允许重试。

间距优先使用 4、8、12、16、20、24、32px 等共享尺度，按内容节奏、对齐和触控需要调整。旧原型中的非标准间距可在相关组件优化时归一或重新设计，不要求为了复刻原型保留。

## 5. 基础组件

### 外部服务集成（2026-10-29）

本节描述新模型已实现的交互语义。领域与权限见[服务集成设计](service-integrations.md)，接口见[服务集成 API](service-integrations-api.md)。布局继续按任务和内容选择，不把历史截图作为模板。

- 控制台模块仍叫“服务集成”，其中的记录统一叫“服务连接”；按钮使用“添加连接”“编辑连接”“删除连接”。目录展示名称、code、服务类型、说明和管理启停，不把启用标成健康。
- 仅展示已实现的服务类型及能力。GitLab、Jenkins、数据库、日志服务使用各自表单；钉钉机器人、邮件和短信属于未来通知模块，不放入服务类型菜单、不出现占位入口。
- 类型筛选、名称/code/说明搜索和启停筛选共享；状态写入 URL，进入详情后返回保留。创建始终使用“选类型 → 连接信息 → 首个凭证”三步向导，类型使用可搜索的紧凑双列选项单选，窄屏单列，选项区域独立滚动；列表保留全部/具体类型入口；窄屏改为带标签下拉。
- 列表与详情保留 code 值和复制入口，不显示“编码”前缀；详情配置表单不重复展示只读 code。
- 创建向导前两步只保存本地草稿，最后提交。首个系统凭证常显名称与编码，不自动设首选或兜底；末步提供“创建连接和凭证”与“仅创建连接”两个按钮，不使用跳过开关；连接成功而凭证失败时保留已创建连接，重试仅提交凭证，也可进入详情继续。返回保留输入，更换类型清空不兼容配置和认证材料并提示，关闭清除秘密草稿。
- 连接和凭证的名称与“编码（可选）”桌面并排、窄屏单列；编码用于程序引用，鼓励自定义，保留留空自动生成和创建后不可修改的契约。添加凭证分“基本信息 / 认证信息 / 有效期与状态”页签，编辑资料仅展示基本信息与有效期/状态，替换认证信息仍为独立操作；校验失败定位对应页签。操作按钮固定在弹窗底部，秘密独占整行，有效期空值表示不设到期时间。连接向导与凭证对话框不展示辅助说明段落、字段帮助与示例文案；保留字段标签、实际连接摘要、错误反馈、空状态和必要的操作确认。
- 连接详情按任务组织“连接配置 / 系统凭证 / Webhook 接收设置”，未支持入站的类型不显示 Webhook 页签。公共资料及服务配置属于同一聚合，可一次保存；分区编辑时也使用同一连接版本，不能用旧的主表/配置两套版本悄悄覆盖彼此。
- 连接 code 创建可选、之后只读；实例地址和公共 CA 等配置仅管理员可见。TLS 放入高级区，不提供跳过证书校验。“测试已保存的连接”不提交草稿、不暗用兜底凭证；验证结果与保存状态分开。
- 系统、项目、个人凭证共用表单和权限判断。项目/个人从有限连接目录进入，只维护本归属的访问凭证，不显示连接内部地址、其他归属数据或Webhook 设置项。归档项目只读。
- 凭证名称和 code 合并展示，独立显示状态、有效期、首选和兜底。“首选”属于当前归属，“兜底”只针对系统凭证且代表缺失时回退；同一凭证可同时有两个标记。新建不自动设置标记。
- 普通资料编辑与“替换认证信息”分开。后者根据服务同时提交完整认证方式、身份和秘密，不能通过旧秘密占位保留材料。关闭/取消清除秘密草稿，不存浏览器持久化存储，保存后仅显示已配置状态。
- Webhook 页签直接展示此连接唯一的接收地址、验证方式、秘密配置状态、启停和最近诊断，无接入点列表、添加/删除入口、名称、说明或 code。
- 新连接默认关闭 Webhook，先导入/生成秘密、配置远端 Hook，再显式开启接收。不提供事件筛选或项目 ID 配置，相关规则由消费方管理。
- 验证方式变更与秘密替换原子提交；生成/导入不隐式启用。轮换提示针对当前连接，说明所有使用此连接地址的远端 Hook 都须更新，其他连接不受影响。Token 生成后一次性展示，已有秘密不可再次读取。
- 接收地址可复制；诊断区分未接收、配置已变化和已接收未分发。未认证请求不写最近摘要，配置保存错误另行提示。Webhook 设置不展示消费规则编辑器，禁止显示“工作流已触发”的成功提示或模拟执行入口。
- 连接停用提示其阻断出站验证和所有入站，但子开关保留；删除连接要求凭证已清空，提示 Webhook 设置和秘密一并删除、接收地址失效，远端 Hook 需自行移除。
- 诊断按独立接口加载，未加载显示“查看记录”，确认 latest=null 才显示“尚无记录”；旧配置结果标注已过时。诊断不使编辑表单版本失效。自然过期前端计算，不能把已配置/未过期等同于外部权限有效。
- 412 保留非秘密草稿并提示重新加载，秘密重新填写；失败不静默覆盖。保证键盘、浅深主题与窄屏可用，相关短字段改单列，列表信息自然换行。

## 6. 品牌与头像

主 LOGO 使用 `web/public/logo.svg`：小圆角正方形，外框圆角半径为边长的 9.375%（48 单位视图中为 4.5），中央为圆脸与折角触角。双眼位于圆脸右上方，左低右高，近侧较宽、远侧较窄；眼睛弧度顺应右脸轮廓，触角根部、方向和远近大小表达同一球面朝向。轮廓根据确认稿转成矢量路径，保持比例，不叠加渐变或立体材质。

LOGO 固定使用陶土色 `#d97757` 与浅色主题画布的暖白色 `#faf9f5`，头部为实色填充。浅色主题使用 `logo.svg`：陶土色底、暖白色头部与触角，双眼为陶土色；深色主题使用 `logo-inverse.svg` 互换两色：暖白色底、陶土色头部与触角，双眼为暖白色。侧栏、登录、安装及欢迎图形直接显示相应双色 SVG，favicon 随外观选择同步切换。LOGO 不叠加半透明或滤镜，保证实色区域保持指定色值。正式资源只包含定稿 SVG，探索稿和预览截图留在 Git 外。

登录与注册页左侧只保留小尺寸品牌标识、主标题及留白；不展示轨道线和放大的占位方块。

常用尺寸：品牌色块 37px，列表头像 38px，侧栏头像 36px，个人资料头像 68px。没有上传图片时统一使用固定 SVG 用户图形和中性背景，不按身份改变底色；有图片时容器背景透明，无边框和阴影，图片采用 object-fit:cover 并由容器统一裁切圆角。裁剪预览同样不加装饰边框。

头像交互：

1. 选择 JPG、PNG 或 WebP，最多 2 MiB；非法文件给明确反馈。
2. 打开固定 1:1 裁剪层；支持拖动、键盘微调、1–4 倍缩放、90° 旋转、重置及重新选择。
3. 同时显示资料与导航尺寸的效果预览；确认后只更新当前表单草稿。
4. 保存资料后才替换正式头像，取消表单保持原图。输出为 256×256 PNG，正式后端仍需重新解码、校验与编码。

登录与注册页移除“连接人与工具，让开发更有序。你的开发协作空间，从 AntCDP 开始。”及表单底部英文全称；关闭注册时，登录页隐藏整行注册入口。侧栏不显示英文副标，公共布局不显示版权和协作标语页脚。个人设置不展示创始人保护说明块，保护规则保持不变。

## 7. 表单与错误

- 登录、注册、个人资料、普通/强制改密和管理用户表单共用字段错误映射与焦点定位。注册及管理用户将用户名和密码完整规则放在对应输入框下；显示名称、用户名格式、密码长度、确认密码不一致、用户名占用、当前密码错误、新旧密码相同和服务端已知字段错误就近展示，按页面顺序聚焦首个错误字段。输入时清除该字段旧错误；错误说明参与布局，不绝对定位，不遮挡后续控件。其他或未知字段/规则保留表单级提示及请求编号；失败保留输入，切页或关闭密码表单清空密码。
- 必填字段有 label 和必填标记，placeholder 仅举例；显示名称支持中文。用户名用于登录，个人设置只读。
- 管理用户弹窗按表单内容确定宽度，640px 是当前桌面参考值，并限制在视口内；标题与底部操作区保持可达，正文超高时滚动。相关字段在空间充足时并排，窄屏改单列；错误提示不遮挡操作。创建、编辑与重置密码共享布局原则，底部保留舒适的留白和按钮间距。弹窗样式需覆盖实际挂载的浮层，避免页面 scoped 样式无法命中。
- 自主注册表单：显示名称、用户名、密码、确认密码；不出现邮箱或身份选择。
- 新密码至少 8 个 Unicode 码点、最多 72 个 UTF-8 字节。界面显示字节上限，前端和服务端按同一规则校验，不用 JavaScript 字符串 length 代替字符/字节计数，不强制字符类别组合。
- 提交过程中禁用重复提交，成功后显示明确反馈；失败保留非敏感输入并定位问题。密码、令牌不写入日志、URL 或正式前端 localStorage。
- 接口错误按 [API 契约](api.md) 的 error.code 处理，details 为数组。包含 field 的条目定位字段，其余条目展示在页面；只解释受支持的 code/context，未知错误回退到 message 和 request_id。
- 开关、资料、头像等编辑只在保存后生效；取消不写入设置或正式资料。系统设置按当前分类保存，显示未保存状态并提供撤销；切换分类、离页和刷新时保护未保存修改，保存过程中阻止切换。
- 侧栏、移动账号菜单和账号安全页的退出入口统一显示“确认退出登录”。取消或关闭确认框不调用退出接口；确认后撤销当前会话并返回登录页。处理中阻止重复触发，失败保留当前页面并显示错误。
- 删除用户要求输入用户名，明确“无法从界面恢复、用户名不可复用”；创始人和自身保护规则优先。
- 强制改密会话进入专门的改密流程；不能通过关闭弹窗、Escape 或导航绕过。正式前端使用独立受限页面，同时提供更新密码和退出登录入口，不显示可跳转至其他业务页面的导航；API 也执行同样限制。
- 空列表、搜索无结果、加载中、权限不足、服务不可用分别展示可理解的状态；数据库不可用不跳转到安装向导。用户和审计列表请求失败显示失败及重试入口，不显示搜索无结果；系统设置初次加载失败可原地重试。
- 安装向导采用居中双栏卡片，“欢迎 → 连接数据库 → 系统配置 → 创始人账号 → 完成”，其中三个配置步骤提交真实数据，不展示安装令牌；仅未安装时开放。连接检查要求空库，提交前再次核验；存在持久化安装锁时展示已安装或维护状态。
- 安装完成显示 5 秒倒计时，自动以 replace 导航进入 `/home`，同时保留“立即进入首页”按钮。离开页面取消倒计时；安装中、维护或服务不可用时不跳转。安装成功仅当前浏览器获得创始人会话。已安装系统再次访问安装页，直接按会话进入首页或登录，不重复倒计时、初始化或补发身份。

## 8. 响应式与可访问交互

断点根据内容何时开始拥挤确定。下表为当前默认方案，可随组件结构和容器宽度调整；验收重点是信息可读、操作可达及无整页横向溢出。

| 参考宽度 | 默认方案 |
| --- | --- |
| 大于 1200px | 240px 侧栏、32px 内容边距，概览可多列 |
| 851–1200px | 224px 侧栏、30px 内容边距；1050px 以下概览统计和侧面板逐步减列 |

表格在容器内横向滚动，不把整页撑出视口。小屏保留“返回工作区”及账号操作。折叠偏好只影响桌面，移动抽屉状态不替代该偏好。移动抽屉打开后焦点进入关闭按钮、Tab 保持在抽屉内、背景不可交互且禁止滚动；Escape 或关闭按钮关闭后恢复触发按钮焦点，切回桌面解除限制，关闭状态的导航不可聚焦。

所有可操作元素可通过键盘到达并有可见焦点；弹窗约束焦点并在关闭后返回触发元素。普通弹窗可取消，强制改密只有改密或退出。动效保持轻微、及时，不依赖动画表达结果；140–220ms 可作为普通过渡的起点。一般动效尊重减少动态效果的系统偏好；现有主动刷新图标的明确例外见第 4 节，不推广为其他动效的规则。

## 10. 正式前端落地

按功能边界组织应用布局、features 和 shared，复用主题变量、基础控件、头像编辑、确认弹窗、错误映射与统一 API 客户端。Element Plus 提供控件能力，使用官方深色变量与本项目语义色映射；库的默认皮肤和旧页面结构都不是设计上限。后续开发先梳理任务与数据，再决定页面布局和组件组合；优化比例、密度和信息层级，避免为了复刻旧页面而保留不合适的几何值。

复用应复用语义和可用性，不要求所有页面长得一样。检查关键任务能否完成、长内容是否清晰、操作是否可发现、状态是否真实，以及双主题、窄屏和键盘体验。纯视觉调整同步相关规范即可，业务、接口和存储契约仅在受到影响时更新；不要求同步不可版本化的本地原型。

一期验收覆盖首页、登录/开放与关闭注册、安装、个人资料/安全、控制台概览、用户管理、系统设置和审计；同时检查管理员与普通用户、空结果、错误、窄屏、键盘、头像取消和强制改密。原型中的每页 6 条演示数据、固定演示口令与模拟数据库检查不是正式产品约束，正式分页与协议以 API 文档为准。

头像编辑在个人资料和管理员用户表单中使用相同组件：确认裁剪只生成上传草稿，保存表单才绑定；取消、切换账号页或关闭用户表单会丢弃未绑定草稿。裁剪弹窗支持拖动、滚轮/滑块缩放、90° 旋转、重置、重新选图和方向键微调（Shift 加速），同时显示资料与导航尺寸预览；读取或上传期间阻止重复提交。

审计列表提供事件标识、只读记录和详情入口。关键词、事件类型、时间范围、清除筛选和刷新按使用顺序组合，空间不足时自然换行；小屏优先保证搜索和日期控件可用，不照搬原型工具栏行数或断点。不显示重复的点击详情与时区说明文字，时间筛选和显示语义保持不变；使用真实游标分页，不显示演示总数。用户与审计列表均提供每页 10、20、50、100 条，默认 10；分别在本机 localStorage 的 antcdp.page-size.users / antcdp.page-size.audit 记忆选择。非法值回退 10，存储受限时保留当次页面选择；修改数量重置页码及审计游标。切换筛选回到第一页；详情包含事件代码、操作者和对象快照、时间、请求编号及经过白名单过滤的变更。概览的最近操作可打开相同详情，并提供“查看全部”导航。

用户与审计列表统一搜索行为：停止输入 600ms 后自动查询，Enter 立即查询并取消待执行的延迟查询；中文输入法组词期间及确认组词的 Enter 不发起查询，组词完成后再延迟查询。状态、身份、事件、时间范围与每页数量变化立即查询并重置页码或游标。两页均提供刷新和清除筛选；清除关键词及本页全部筛选（含审计时间范围），保留每页数量偏好并回到第一页，无筛选时禁用清除。输入开始即将旧请求标记为过期，只有最新请求能更新列表、数量、错误和加载状态；离页取消待执行查询。搜索和筛选不触发刷新旋转动画。

## 11. 工作区任务入口优化（2026-10-28）

首页优先展示“我的项目”“我的团队”两个任务入口和真实的已固定项目、团队；欢迎语使用“欢迎回来，{显示名称}。”，显示名称缺失时回退用户名；首页不重复展示系统名称、控制台入口或底部账号链接。移除入口副标题、区块说明与重复引导，只保留必要的空状态、加载和错误提示。固定项加载、失败重试、空状态分别呈现，不把加载失败解释成没有项目。未参与的用户通过明确说明了解加入方式，不展示虚构统计或动态。

## 13. 项目与团队详情布局（2026-10-28）

### 凭证标识维护

各服务共用凭证 code 字段：创建时可选，留空由服务端生成无短横线的 UUID；同服务类型跨连接和归属唯一。列表展示 code，编辑时只读，名称和说明仍可修改。GitLab 不再显示令牌类别选择器，用途由说明表达。格式错误保留草稿，重复 code 提示冲突而不展示其它归属的信息。

### 服务集成工作台

服务列表采用类型菜单与结果区两栏，类型菜单不提供搜索、独立滚动，类型来自真实服务能力和连接数据，不展示未实现服务占位。即使只有一种服务，仍显示“全部服务”和对应类型入口及数量；窄屏使用带标签的类型下拉。类型写入 URL 查询参数，刷新、进入详情和返回时保留；名称/code/说明搜索与启停状态可组合，空结果提供清除筛选。

服务连接采用紧凑表格，名称和详情头部使用服务图标，优先呈现名称、code、说明、类型和启停。控制台详情顶部使用“服务集成 → 服务类型（如 GitLab）→ 连接名称”三级面包屑，前两级分别返回全部连接和该类型列表；详情区不再显示“返回连接列表”或名称上方的服务类型文字。个人凭证详情沿用类型层级，项目凭证保留项目上下文层级。详情保留连接/凭证/Webhook 接收设置导航；Webhook 使用连接内的一份共享配置，不提供接入点集合。系统、项目和个人共用类型筛选，权限按新领域契约执行。连接高级 TLS 折叠，凭证 code 用等宽字体。

凭证支持名称/code/说明搜索及可用、即将到期（7 天内）、已过期、已停用、未配置秘密筛选；这些是记录状态，不代表外部服务验证成功。code 提供复制入口。行内保留编辑与更多菜单，替换认证信息、验证、首选、兜底和删除收纳在菜单内。未加载验证结果显示“查看记录”，请求确认无记录后才显示“尚无记录”。创建表单按基本资料、认证材料、有效期分组；普通编辑与完整认证替换保持独立。

控制台项目管理、团队管理和用户管理的列表工具栏沿用审计日志的搜索框样式、控件对齐和间距，依次排列搜索、状态分段筛选、其他筛选、清除筛选、刷新与创建操作；窄屏自然换行。状态分段控制器保留各页原有三个选项、计数和默认值，使用浅色底座（深色主题对应表面色）、圆角边框，选中项使用独立表面色与轻微阴影，支持键盘切换。工作区状态页签与表格列标题不变。

工作区“我的团队”沿用同一列表工具栏、状态分段控制器及总数/每页数量/翻页布局，保留横向团队列表及原有权限，不提供控制台专属创建入口。“我的项目”和详情成员分页保持原行为。

统一列表工具栏下的加载与空状态和底部分页使用连续的表面色与左右边框，形成完整面板；空状态不重复工具栏已有操作。结束状态（归档/解散）或搜索无结果时提示调整筛选，不显示加入团队或创建资源的引导。

### 服务连接编码与详情操作（2026-10-29）

连接 code 的界面文案统一为“编码”。列表图标右侧按名称、编码两行排列；详情编码位于名称下方，使用 13px 次要色等宽字体。长编码单行省略，提供完整值提示和复制按钮。详情移除顶部“编辑资料”，资料统一在连接配置中编辑；更多操作使用轻量省略号按钮，菜单项带图标，删除使用危险色。GitLab 地址支持 HTTP、HTTPS、自定义端口及子路径；HTTP 时禁用高级 TLS 的 CA 输入并保留原值。

### Jenkins 服务集成

Jenkins 与 GitLab 共用服务连接和凭证导航，连接配置包含实例地址与公共 CA，支持部署子路径。Jenkins 凭证创建/认证替换填写用户名和 API Token；用户名可展示和搜索，Token 保存后不可读取。Jenkins 不显示 Webhook 页签。连接测试显示 HTTP 可达与服务识别，凭证成功明确标注“身份认证成功；构建权限未验证”；代理拒绝、重定向、身份不匹配和异常响应给出具体原因。

对话框底部使用可换行的 flex 布局和显式 12px gap；嵌套按钮组也必须自行设置 gap，不依赖 Element Plus 的相邻按钮外边距。向导底部保持取消在左、步骤和提交操作在右，窄屏换行后保留行列间距。

服务集成列表顶部内边距收紧为 16px，类型导航与列表区域不再额外叠加顶部外边距。列表、详情及凭证列表的编码复制共用组件：复制成功后原位显示绿色勾，2 秒后恢复复制图标；再次复制重新计时，失败显示错误而不显示成功状态，卸载时清理计时器。

凭证列表沿用用户管理表格的工具栏、14px 内容字号、行内边距、底部计数与操作布局；添加凭证位于筛选栏右侧。编辑、更多操作和查看记录提供悬停/键盘焦点反馈，弹出菜单项带语义图标。服务连接目录在现有完整目录接口上进行前端展示分页，默认 20 条，可选 10/20/50/100 条；先筛选再分页，筛选或每页数量变化回第一页，URL 保留查询和页码，详情返回恢复。该分页不减少接口读取量。

服务连接表格与分页页脚置于同一面板，页脚复用用户表格的内边距，仅保留表格与页脚之间的一条分隔线，避免独立表格外框与页脚上边框叠加。凭证行内只保留更多操作入口，“编辑凭证”作为菜单首项，带编辑图标。

凭证列表始终按“筛选工具栏 → 内容区域 → 计数页脚”排列。加载、错误、无凭证、无筛选结果与表格互斥呈现在内容区域；该区域顶部统一一条分隔线，空状态不另加虚线边框或外边距。加载及错误时不显示计数，避免误报 0 条。

服务集成连接测试、系统/项目/个人凭证验证与 Webhook 接收结果共用语义文字色：成功绿色、失败红色、暂不支持黄色、未知或无记录中性灰色。按最终诊断状态判色，HTTP 可达不覆盖认证失败。历史结果优先显示黄色“历史结果”与灰色原结果，避免误认为当前有效；时间、身份、事件和项目保持次要色。Webhook 已验证接收为绿色，“未分发工作流”为次要色；连接与凭证成功继续保留未验证身份、具体业务权限未验证等边界说明。复用浅深主题变量，保留文字含义和紧凑布局。

连接详情页顶部只保留外层 20px 留白，详情自身不再叠加顶部内边距；标题去掉上边距，页头不叠加底部内边距，页头与连接页签间距为 12px，页签与内容间距为 20px。空描述不渲染占位段落；长名称和描述自然换行，列表及其他页面间距不受影响。

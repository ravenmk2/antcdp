# UI 设计规范

## 1. 规范的适用方式

本规范描述当前前端的视觉与交互约束。业务字段、权限、状态机和 API 以所属领域文档为准；界面不能为了美观隐藏风险、伪造结果或扩大权限。

| 类型           | 维护规则                                                                    |
| -------------- | --------------------------------------------------------------------------- |
| 产品与操作约束 | 导航归属、权限、数据真实性、保存/取消、版本冲突、未知结果和可访问性必须保持 |
| 视觉默认值     | 字号、间距、圆角、阴影和宽度是设计起点，可按真实内容调整并复用语义变量      |
| 页面组织       | 按任务和对象层级安排，不把历史页面或原型示例当作固定模板                    |

AntCDP 的当前视觉采用海蓝强调、冷色中性画布、轻量边框和低阴影面板。浅色、深色和跟随电脑共享信息层级。正式界面、标题、菜单和 Logo 旁文案不使用内部主题代号。

### 新功能的设计原则

新增或重构前端功能时，先确定用户需要识别什么、比较什么、完成什么操作，再根据内容长度、操作频率和风险选择布局与组件。以下原则用于设计评审；具体尺寸、列数和字段顺序按场景决定，不机械复制主机页面。

1. **列表服务于识别、比较和操作。** 名称、地址、状态等判断依据直接展示；长度不确定且不参与主要比较的说明按需展开，不用一列截断长文本代替阅读入口。决定是否收起信息要看任务，不能隐藏风险或影响决策的关键内容。
2. **补充信息支持预览与完整阅读。** 有内容时显示轻量入口，支持悬停和键盘聚焦预览；需要长时间阅读、选择或复制时，点击打开可固定查看的 Popover 或详情。长文本换行并局部滚动，不撑开列表；入口有可访问名称，弹层支持 Escape 和焦点恢复。关键内容与操作不能只能通过悬停获得。
3. **表单按字段内容排布。** 短字段可并排，说明等长文本独占一行并使用多行输入框。关联字段共同确定对齐线与列宽，避免各行因按钮或辅助信息不同而错位；帮助文字与错误信息不破坏同排控件对齐。只读编码等身份字段在有助于识别对象时展示，不单纯为凑齐偶数添加字段；只读值仍可阅读和复制。
4. **操作按频率与风险分层。** 常用的主要操作直接可达，低频操作收纳到“…”菜单；危险项明确区分，执行前说明目标与后果。收纳入口不改变权限、禁用条件或确认要求，核实未知结果等恢复操作保持容易发现。
5. **操作容器保持任务上下文。** 从列表发起且需要保留列表上下文的多字段操作优先使用抽屉；只有存在明确先后关系时才分步。确认步骤展示可读摘要及关键影响，不重复整张可编辑表单，不回显敏感材料。返回上一步保留草稿，关闭未保存表单需确认，提交期间防止重复操作；长篇编辑和复杂持续任务使用独立页面时，把主要空间留给内容，操作集中在工具栏；短表单与辅助工具按任务设置宽度上限。
6. **反馈说明问题与下一步。** 同一提交错误只显示一处主要提示，字段错误就近展示并引导聚焦；错误码、请求编号等诊断信息收纳到技术详情。提示不要求用户理解内部协议，不展示无依据的等待时间。版本缺失或冲突提供明确的重新加载入口，保留可保留的草稿，由用户核对后再次保存；结果未知先核实，不自动重放写入。
7. **选中、焦点和滚动分别设计。** Tab 使用图标与文字共同表达分类，选中状态与键盘焦点可区分。边框、下划线和焦点样式不应引入无意义的滚动条；优化默认焦点外观时仍需保留可见的键盘焦点及强制颜色模式支持。滚动归属于需要承载长内容的区域，不能靠裁切掩盖不可达内容。
8. **信息按职责组织，避免重复展示。** 导航标识当前对象，标题和元信息帮助识别，正文承担阅读，目录负责定位。少量基础信息可以紧凑展示，不必单独占据侧栏；正文已有标题时不添加重复 Header，数量靠近对应内容入口，用户需要的编码等标识保留复制能力。
9. **用真实内容和异常状态验收。** 在目标桌面实际可用视口检查超长说明、长名称、空内容，以及加载中、失败、版本冲突和结果未知；同时复核键盘、焦点、浅深主题和系统缩放。正常短文本下的截图不能代替这些检查；具体行为检查和验证记录要求见第 9 节。

组件与容器规则见第 6 节，列表规则见第 7 节，各领域的具体交互见第 8 节，桌面验收边界见第 9 节。

## 2. 语义变量与品牌

`web/src/styles/app.css` 统一维护语义变量。组件使用变量或 Tailwind 映射，不在页面中逐处重定义控件皮肤。参考图和官方示例用于理解信息结构、控件形态与交互；引入后按产品语义变量适配配色，并按任务调整字体和密度，复核浅深主题。

Logo 使用 `web/public/logo.svg` 和 `logo-inverse.svg`，保持原始图形和比例：蓝色底为 `#2563EB`，内部图形为 `#FAF9F5`；反白版本交换两色。登录/注册左侧固定深蓝背景并使用反白 Logo。服务品牌使用 `public/service-icons`：OpenObserve 保留原始彩色，其余已支持服务使用按类型区分的纯色 SVG；浅深主题保持透明背景，不添加白色底块。连接详情标题下不再单独重复服务类型名称。通用图标使用 Lucide；不使用 Emoji 或字符充当操作图标。

## 3. 排版与密度

首选系统字体，不下载或加载额外字体：

```css
font-family:
  "Microsoft YaHei UI", "Microsoft YaHei", "Segoe UI", "PingFang SC", sans-serif;
```

| 内容                         | 当前规格             |
| ---------------------------- | -------------------- |
| 正文、表格主要内容、主要控件 | 14px                 |
| 页面主标题                   | 27px，配合字重和间距 |
| 面板标题                     | 14–16px              |
| 普通按钮 / 紧凑按钮          | 14px / 12px          |
| 表头与辅助正文               | 12px，不用于长段正文 |
| 字段提示与非关键元信息       | 11px，保持可读对比度 |
| 登录/注册标题                | 26px                 |
| 安装与复杂流程标题           | 25–27px              |

代码、分支、SHA、ID、版本、Tag 和请求编号使用等宽字体，长值允许换行或局部滚动。中文正文不使用等宽字体。以文稿为主要内容的 Markdown 编辑器与阅读预览统一正文字体、基础字号和行高；行号及预览中的代码仍按代码语义使用等宽字体。编辑器的折叠箭头等操作标记遵循第 2 节 SVG 图标约定，避免字符字体回退造成形态差异。不要用全局缩放压缩整个应用；按组件语义调整密度。

## 4. 外观与应用壳

外观偏好支持浅色、深色和跟随电脑。`theme-init.js` 在应用加载前设置主题，监听系统变化；用户菜单的外观入口显示当前偏好，二级菜单展示三项并用可见勾选标记当前选择，支持方向键、Escape 与焦点恢复。顶栏纯图标按钮按浅色 → 深色 → 跟随电脑循环。只有外观、侧栏密度和每页条数等非敏感偏好可写入 localStorage。

| 区域            | 当前默认值                                                  |
| --------------- | ----------------------------------------------------------- |
| 展开侧栏        | 252px，100dvh，中部导航独立滚动                             |
| 折叠侧栏        | 72px，保留图标、焦点和可访问名称                            |
| 顶栏            | 64px，不透明主题表面，细分隔线，右侧为纯图标操作            |
| 内容区          | 最大 1540px，桌面内边距约 28px 32px；复杂交付可占满可用宽度 |
| 面板 / 控件     | 10px / 7–8px 圆角                                           |
| 弹窗 / 登录窗口 | 13px / 18px 圆角                                            |

工作区一级入口只有首页、我的项目、我的团队；进入具体项目后才在主导航上方显示项目切换器与项目导航。控制台入口仅出现在系统管理员用户菜单，侧栏仅保留顶部品牌与控制台标识，不再重复显示管理员身份说明区，顶栏提供纯图标返回工作区。个人设置通过用户菜单进入。消息按钮只是预留入口，不显示虚构未读数。

首页采用关注项目卡片与固定团队的双栏布局，项目卡片展示摘要、成员数和本人角色，下方继续展示当前项目的真实发布与待核实操作。项目总览以当前发布和六阶段流程为核心，配合资源摘要与活动产品分支；发布详情复用相同的阶段卡。子页面不重复显示项目标题或横向页签，项目导航统一由左侧承担；资料编辑和退出仍可在总览与项目设置中操作。

侧栏展开与折叠采用约 200ms 的宽度过渡，文字淡入淡出，分组标题同步收起，避免导航和图标突然跳动；折叠态隐藏文字不参与键盘焦点。个人设置分类图标与侧栏一致为 18px，选中与未选中使用相同字重，通过背景和颜色表达状态。

顶栏使用 `--surface` 不透明底色，不使用背景模糊，避免与弹层遮罩叠加滤镜；抽屉和对话框遮罩仍保留第 6 节规定的 2px 背景模糊。顶栏创建、返回、主题和消息按钮均有 `aria-label` 与悬停提示。侧栏导航选中项与未选中项保持相同字重，通过背景和文字颜色表达当前位置。侧栏底部用户菜单包含身份、个人设置、外观、管理员空间切换和退出登录；仅在退出登录上方保留分割线，退出登录使用普通菜单文字与悬停色。

全站密码输入框通过公共组件提供独立的明文显示/隐藏按钮，支持键盘操作，不触发表单提交；焦点离开该控件后恢复隐藏。保留字段值、自动填充语义与校验关联；禁用表单时切换按钮同步禁用。自动填充背景和文字使用当前浅深主题颜色，并保留聚焦环及只读/禁用背景。

## 5. 公共访问与安装

登录和注册使用居中的对话框内分栏，桌面参考宽度 960px、最小高度 580px；左侧只保留 Logo 和背景视觉，右侧为真实表单。注册包含用户名、显示名称、密码和确认密码；关闭注册时不显示入口。强制改密包含当前密码、新密码和确认密码，只允许改密或退出，不显示业务导航。

安装是独立四步页面：连接数据库 → 系统信息 → 创始人账号 → 完成。数据库检查通过后才能继续，返回保留草稿，换步后聚焦标题。安装失败或响应丢失必须区分已确认错误、状态变化和结果未知；不得自动重放安装。完成后停留展示系统名称、公开访问地址、时区、创始人账号、显示名称和数据库名，不展示密码；仅点击“进入系统”后进入首页或正常登录，不设倒计时。当前成功页不因后台状态重新查询而离开；刷新或重访仍走正常访问守卫，仅成功响应对应浏览器获得创始人会话。

安装面板顶部左侧放置 32px Logo 与 AntCDP，右侧为四步进度，下方使用细水平线分隔；面板左右内边距 32px，标题、双列表单与底部操作区共用对齐线。单行控件高 40px，字段内容顶部对齐，帮助文字不拉伸同排控件。提示之间留 12px、与表单留 20px；检查失败、重试成功和连接参数变更时清理失效反馈。底部右侧依次为“检查连接”“下一步”，后续步骤的“上一步”靠左，最终操作为“确认并安装”。不显示面板外的空库检查说明。

全站数字增减输入统一复用基于 Base UI Number Field 的 `NumberInput`，使用右侧弱化上下箭头、40px 高度和共享焦点/错误样式。支持手动输入、清空、键盘增减及 pending 禁用；数据库、SSH 和 SMTP 端口范围为 1–65535，会话有效期为 1–30 天，空值保持草稿并由表单校验，不自动转换为 0。TLS 选择器使用普通下拉，时区选择器使用 shadcn/ui Combobox：弹层顶部搜索、按 IANA 时区名称即时筛选，不区分大小写，无匹配时显示提示；搜索文本不作为时区值提交，关闭后保留选中项，再次展开重置搜索。两类选择器使用弱化下箭头、限高可滚动浮层和约 150ms 淡入淡出及轻微缩放；按已确认交互要求，此处弹层动画不随系统减少动态效果设置关闭。浅深主题保持相同尺寸，菜单支持键盘选择、Escape 关闭和焦点恢复。

服务异常、数据库不可用、初始化中、恢复所需和未安装是不同页面状态；503 不跳安装，401 不显示空数据。

## 6. 组件与操作容器

| 复杂度                     | 容器               | 示例                                   |
| -------------------------- | ------------------ | -------------------------------------- |
| 简单表单、短确认           | 弹窗               | 角色状态、短设置、归档/删除确认        |
| 多字段且需要保留上下文     | 抽屉               | 成员、凭证、材料、仓库关联             |
| 有明确先后关系             | 分步抽屉或独立向导 | 项目创建、分支创建、服务与主机创建     |
| 复杂、持续工作或需要深链接 | 独立内容页         | 发布、产品分支、连接、主机、模板和安装 |

弹窗/抽屉使用 Radix 焦点陷阱、Escape、焦点恢复、独立内容滚动和固定操作区。所有对话框、确认框和抽屉的遮罩统一使用 2px 背景模糊，弹层内容本身保持清晰；叠加确认框同样模糊其遮罩后的内容。右侧面板使用本地 shadcn/ui Sheet（Radix 版本），保留普通 540px、宽版 720px 的桌面宽度和原有表单布局，动效对齐新版官方的 2.5rem 短距离位移与透明度变化，入场和退出均为 200ms，使用 ease-in-out；面板使用轻量阴影。对话框采用 100ms 淡入和 95% 到 100% 的轻微缩放，受控挂载期间支持对应退出动画。遮罩使用 100ms 透明度动画，2px 背景模糊始终固定；遮罩关键帧不包含 transform/filter，面板关键帧只改变 transform/opacity，避免通用动画引入无用的 filter。条件渲染的抽屉表单在退出动画完成后才卸载，关闭后恢复入口焦点。pending 保留按钮尺寸并阻止重复提交；未保存状态依据实际字段变化判断，未修改表单关闭无需确认；关闭按钮、取消、Escape 和离开导航共享修改检测与放弃确认。应用内导航使用 Router blocker，刷新和关闭标签页使用 `beforeunload`，离开不等于取消服务端工作。

对话框按任务使用两种布局：`ConfirmDialog` 用于放弃修改、删除、退出等确认，标题、后果说明和按钮采用紧凑的连续表面，不显示标题与操作区分隔线，不为空正文预留高度；有输入确认、错误或恢复提示时按实际内容展开并允许滚动。`Modal` 用于短表单、详情和辅助工具，保留标题、可滚动正文及固定底部操作区的分段布局。两者共用遮罩、动效与焦点管理，宽度按内容选择，不能通过固定高度填充空白。

字段使用公共表单组件提供的标签与错误关联，动态增删的输入项也必须具备完整的字段上下文。字段具有稳定 label、说明、必填状态、错误和 `aria-describedby`；输入时清理旧错误，保存失败保留非敏感草稿。密码、Token、私钥和秘密不持久化，不在普通详情中回显。

Toast 只承载轻量结果；错误、版本冲突、部分成功和结果未知留在对应操作区。复制、刷新和下载提供真实反馈，不虚构成功。

### 结构化配置与输入语义

参数定义、字段映射等配置默认使用结构化表单，按项提供名称、类型、说明、必填和适用的默认值；复杂结构按内容组织，保留高级 JSON 入口。表单与 JSON 切换必须保留字段、数据类型、默认值和未保存内容。遇到表单无法表达的结构或无法识别的字段，保留原始草稿并说明原因，不能静默删除、转换或用空对象覆盖。

“未提供”与空字符串、`0`、`false` 是不同的输入状态，控件应提供明确的省略或移除方式，不能用真假判断代替是否提供。文本参数保留前导零；数字和布尔值按领域契约保持原生类型。默认值用于契约允许的缺省行为，样例用于预览或辅助填写，两者分别标注；不得把样例自动当作运行默认值，也不能擅自用默认值绕过必填校验。

未命名的新参数、重复名称、未完成的数字或 JSON 都属于需要保留的编辑草稿。输入过程中允许这些中间状态，就近提示错误，并阻止依赖该输入的保存、预览或执行；不能自动纠正为另一个有效值、退回旧值或丢弃其他字段。错误恢复后继续使用当前草稿，字段定位、键盘与焦点遵循本节表单约定。

### 详情信息与操作入口

详情中的业务编码等稳定标识优先放在字段展示区；需要持续辅助识别时可放在标题下的紧凑元信息区，同一值不在两处重复。按第 3 节排版规则展示长值，需要复制的标识提供独立复制按钮，反馈与焦点处理遵循第 8 节。

详情操作按第 1 节的频率与风险分层，同一操作不在页头和内容面板重复铺设。返回上级属于导航，不混入业务操作菜单；面包屑已提供等价路径时省略重复返回入口，需要保留编辑上下文或返回特定列表条件时可单独提供。错误恢复操作保留在对应错误附近。

列表和详情的更多操作统一使用本地 shadcn/ui Dropdown Menu，以水平三点作为入口，提供可访问名称；菜单项带 Lucide 图标，危险项在底部分组并使用危险色，保留权限、禁用和确认规则。菜单支持方向键、Home/End、Escape 与焦点恢复；选择菜单项打开弹窗或抽屉时，先关闭菜单再交接焦点，避免菜单恢复焦点与新容器的初始焦点互相覆盖。

### 模式切换与状态按钮

同类显示模式使用一致的分段控件，例如编辑／分栏／预览、代码／图形；使用 shadcn Toggle Group 单选，并保持始终有一个有效模式。外观采用次级表面底座、主表面选中块和轻阴影；字号、间距和宽度按所在工具栏的密度调整。分类导航继续使用 Tab，操作命令使用按钮，按语义选择组件。

分类 Tab 切换后只展示当前分类，退出的内容不能继续占据布局或参与键盘焦点；保留筛选或草稿状态不等于保留旧页面的可见布局。页面内容切换与弹层关闭分别管理，不能让普通列表依赖弹层退出动画才能消失。列表详情抽屉保留背后的列表上下文，关闭后恢复筛选、分页和触发焦点。

查找面板、自动换行等开关按钮必须反映真实生效状态。含义明确的高频工具可使用图标入口，提供可访问名称、悬停提示和可见选中状态；面板的快捷键、关闭按钮和 Escape 操作，以及同一开关的其他入口，都同步真实状态。再次点击开关应能关闭对应能力或面板，选中状态与悬停、键盘焦点分别可辨；有歧义或需要说明后果的操作保留文字。

### 持续编辑与阅读

长篇编辑工作区可铺满全局导航下的可用内容区，避免固定页面宽度、重复标题和外围卡片挤占正文。保存、返回、下载、显示模式和辅助工具集中到工具栏，状态反馈就近展示；仍保留未保存保护、提交防重和错误恢复入口。

工具面板的宽度由任务决定，不随单栏内容区无限拉伸。查找和替换等关联输入共享网格列宽，按钮数量和匹配计数变化不改变两行输入的对齐；较窄内容区可调整辅助控件位置。分栏分割线保持轻量，拖动命中区与视觉宽度分开设置，同时支持键盘调整。

预览应明确对应的草稿状态。正文、参数定义、映射、样例等任何影响输出的内容改变后，旧预览须标记过期或清除；异步返回的旧结果不能被标为当前预览。后台刷新不覆盖正在编辑的草稿；版本冲突读取最新资料供核对，再由用户决定如何继续保存，不能静默替换草稿或采用新版本覆盖他人修改。

阅读目录按内容结构生成，有标题时提供层级定位与当前章节状态，无标题时省略；长内容提供回到顶部。编辑预览的滚动限定在对应内容区，分栏左右滚动按内容位置双向同步，避免图形或长代码的高度差造成章节错位及来回跳动。

### 代码与图形展示

共享代码块统一容器、主题、换行、复制、下载、限高滚动和键盘访问能力；行号等辅助信息按阅读任务配置，Markdown 普通代码默认显示行号。普通代码采用 shadcn/ui Base CodeBlock 示例的浅灰表面、文件图标及标题和右上角操作，浅深主题使用 GitHub Light / GitHub Dark 高亮；高亮加载或失败时仍可读取、复制完整纯文本。换行必须实际改变长行的布局和溢出行为，不能只改变按钮状态。

Markdown 围栏可用 `title="path/file.ts"` 指定标题、`{6-10}` 标记高亮行；无文件名时显示语言，不虚构路径。普通代码与 Mermaid 容器保持一致的圆角，当前默认 8px。Mermaid 默认代码，显式切换图形后按需渲染；代码／图形切换固定在块工具栏最右侧，复制和放大查看位于其左侧，模式变化时切换入口保持位置稳定；内嵌图形等比缩放完整显示，点击遮罩查看器支持滚轮/按钮缩放、拖动/方向键移动、适应窗口、实际大小、SVG/PNG 下载及 Escape 关闭。打开查看器时隐藏正文回到顶部按钮，关闭后恢复触发焦点。

## 7. 表格、筛选与分页

表格外壳负责完整上下圆角，内部 `table-scroll` 只承担局部横向滚动，不继承圆角；内容行悬停背景铺满整行，圆角由顶部工具栏和底部分页所在的外壳裁切，不影响行操作或分页。表头使用次级表面，行悬停使用悬停变量，主要内容 14px。TanStack Table 只负责复杂列和行逻辑，不决定视觉。

操作列表头和行入口统一右对齐。用户、凭证、项目仓库、产品分支、交付材料、发布变更与送验清单的多项操作收纳为单个水平三点按钮，菜单及焦点交接遵循第 6 节。只有查看、进入或下载的列表保留直接入口；成员角色、SQL 排序、批量选择、分支执行及未知结果核实保持直接可达。

筛选变化回到第一页并清空失效选择或游标。用户和审计搜索停止输入 600ms 后查询，Enter 立即查询，中文组词期间不查询；旧请求由 Query 取消与 Key 隔离。加载、失败、空数据和筛选无结果分别展示，失败不伪报 0 条。

列表工具栏统一由 `TableToolbar` 组织：左侧为关键词、常用筛选、重置和刷新，右侧为添加、创建、关联等列表操作；不在页头重复创建入口。关键词默认宽 240px，仓库路径与发布搜索使用 280px；状态选择约 160px，对象和事件类型选择约 200px。主行控件高 40px，在 1920 桌面实际可用视口内保持单行。低频条件过多时放入下方可折叠高级搜索，入口显示已生效条件数，收起不清除条件。高级筛选在桌面可用宽度内优先横向排布相关字段，按内容长度分配列宽，保持标签与控件对齐；字段数量、长内容和缩放需要时允许换行，不固定列数，也不为减少高度而挤压可读性。共用辅助说明集中紧凑展示，避免每个字段纵向独占一行挤占结果列表。

重置和普通列表刷新使用描边图标按钮，提供中文提示、可访问名称和键盘焦点。重置恢复该列表默认筛选，并同步清理尚未提交的关键词、时间与高级条件；刷新保留当前条件，请求期间旋转且阻止重复点击。同步信息、确认刷新范围、清理预览和结果核实等业务操作保留明确文字及原有确认流程。

普通单选统一使用本地 shadcn/ui Radix Select，覆盖列表、表单与行内角色；已有时区 Combobox 保留搜索能力。弹层限高滚动、长选项换行，触发器不随长文字撑宽。保留空值、禁用项、表单提交值、字段错误聚焦和 Escape 焦点恢复，弹出时淡入与轻微缩放。

审计与邮件/短信发送日志使用单个时间范围按钮打开双月日历：左侧提供今天、昨天、近 24 小时、近 7 天、近 30 天，审计另有全部时间；日期按周一开始，支持手输 `YYYY-MM-DD HH:mm` 和单边范围。编辑弹层只修改草稿，应用后查询，取消不改变已生效条件。完整日期范围包含选中的结束日，并转换为次日零点的排他上界；手输结束时间保持排他语义。输入、展示与转换统一使用系统配置时区，弹层明确标注时区与 24 小时制；拒绝无效日期及夏令时跳过的时间。消息日志仍受最近 30 天保留期限制，旧 `days` 链接继续兼容，自定义范围使用既有 `from`/`to` 参数。凭证到期时间使用单月日历与时分输入，支持清空，提交 UTC 时间。

所有分页导航左侧显示真实总条数，右侧依次为每页 10/20/50/100 条选择（使用 shadcn/ui Radix Select，触发器宽 64px；菜单保留官方淡入淡出、95% 缩放及随弹出方向滑入的动画，按已确认要求不随系统减少动态效果设置关闭，支持键盘选择、Escape 关闭和焦点恢复，加载时禁用）、{当前}/{总页数}（如 1/2，不显示“第”“页”，保留完整可访问名称）、首页/上一页/下一页/末页四个描边图标按钮（双左、单左、单右、双右箭头）。不再显示数字页码按钮组。空列表显示共 0 条、1/1；边界方向禁用，加载期间数量选择与导航全部禁用；按钮提供中文可访问名称和键盘焦点。审计使用页码分页并将页码、每页数量保存在 URL。远端仓库和 MR 候选未提供总数时，左侧显示“总数未知”，总页数显示“—”，末页禁用，保留首页与可用前后页；不扫描全部远端数据来拼凑总数。服务连接和 SSH 主机等完整目录在前端筛选，不增加无意义的服务端分页。

审计日志列表采用单行文字：事件名称与事件代码分列，操作者展示名称与次级色的 @账号在同一列同行；长内容省略并保留完整悬停提示，详情内可读取全文。整行点击打开详情，聚焦行后 Enter/空格同样可打开，并保留右侧查看按钮与关闭后的焦点恢复。详情的 ID 与对象放在字段展示区第一行并排展示；8 个字段按两列四行排列，标题下不再重复 ID。“操作数据”使用第 6 节共享代码块展示格式化 JSON，默认换行且无行号，不改变服务端返回的白名单内容。

## 8. 任务与恢复状态

复制操作统一反馈成功或失败，代码、Markdown、Mermaid 与普通字段使用相同机制。HTTP 部署下剪贴板 API 不可用，或浏览器拒绝该 API 时，尝试用户点击触发的兼容复制；两种方式均失败才显示失败提示。复制结束后恢复原焦点与选区，弹窗内操作不得被焦点陷阱打断。

安装向导切换步骤时，在新内容挂载后同步聚焦标题，不使用延迟动画帧抢走用户已经移入输入框的焦点。

### 项目、团队与仓库

团队、项目的新建和编辑统一使用单一图标预览及“更换图标”浮层（入口文字使用普通文字色）；紧凑网格展示内置图标，选中后关闭并更新表单草稿。上传进入裁剪，取消保留原图标；非默认状态提供恢复默认。图片裁剪滑杆与滚轮均支持 1–10× 缩放。

初始管理员与添加成员共用用户选择器：多选弹窗左侧候选、右侧已选，单选省去右栏；确定才回填，取消保留原值。按姓名和账号搜索，停止输入 300ms 后查询，Enter 立即查询，中文组词期间不查询。候选与已选独立限高滚动，搜索变化保留已选；支持全选当前结果和清空已选，超限提示而不截取。用户候选接口返回全部匹配的正常用户，不截断前 50 人，支持约 100 人完整浏览；有头像时通过登录鉴权接口显示真实头像，无头像时使用默认占位。表单最多显示 3 位标签及总人数，多余部分使用“另 N 人”入口。允许暂时清空必选字段，但空选时不能确定或提交；字段错误引导聚焦。

工作区只显示当前账号参与的对象；控制台管理全部对象。项目成员列表区分有效角色、直接角色、团队来源和账号状态。归档、恢复、解散、退出、删除和逻辑删除必须说明目标与后果；团队解散要求输入编码，用户删除要求输入用户名。

控制台团队列表显示名称与编码、成员数、状态、最近更新和操作；不显示当前操作者的资料权限列。摘要通过信息图标预览或固定阅读，编辑和解散使用行操作菜单，解散保留编码确认及版本检查。编辑从列表读取最新完整资料后打开抽屉。团队表格不设置整行点击，通过名称链接或操作菜单进入详情。

控制台团队详情默认进入团队信息，随后为成员管理、关联项目；已有 `tab=overview`、`tab=members`、`tab=projects` 保持兼容，`tab=settings` 映射到团队信息。成员人数放在成员管理页签的弱化圆角徽章内，选中时使用浅蓝底，显示真实数字。成员表只显示成员、团队角色、账号状态和操作，成员姓名前展示 36px 圆形头像，无头像使用现有用户占位图标；项目成员表继续展示来源。关联项目入口保持控制台上下文。

页头保留团队名称、状态和更多操作；编辑资料、编辑描述归入更多菜单。顶部面包屑展示真实团队名称。编码及复制、创建和更新时间作为标题下紧凑元信息，摘要按需另起一行；基础信息不再占侧栏。团队描述直接展示 Markdown 正文，不重复添加描述标题。右侧 248px 仅放吸顶目录，正文限制舒适阅读宽度；目录遵循第 6 节阅读规则，长标题换行，窄内容区使用弹出目录，滚动超过一屏显示回到顶部。

创建团队使用单页分组 Sheet：基本资料、初始管理员，内置图标库按需展开；描述在创建后独立编辑。编辑团队编码只读，管理员搜索保留已选身份标签。团队描述编辑器采用第 6 节持续编辑工作区，默认左右分栏；对象名称由顶部导航呈现。

团队描述编辑的当前默认值如下，按第 1 节视觉默认值维护，不扩展为所有页面的固定尺寸：

| 场景                      | 当前默认值                              |
| ------------------------- | --------------------------------------- |
| 编辑正文与预览            | 产品正文字体、14px、1.85 行高；行号等宽 |
| 编辑器及 Mermaid 模式切换 | 12px 字号，使用统一分段样式             |
| 分栏分割线                | 4px 可见宽度，保留扩展拖动命中区        |
| 查找替换面板              | 最大宽度 640px，两行输入等宽、14px 字号 |

查找替换包含匹配计数、大小写／全词／正则切换、前后匹配、替换及全部替换，保留撤销、只读保护和关闭后的焦点恢复。分栏预览采用弹出目录，单独预览可展示侧栏目录；目录和回到顶部只操作预览容器，分栏时同步源码位置，不滚动外层页面。

仓库快照时间不代表实时健康。关联、解除、同步、分支校验和创建分别确认权限与范围；多仓操作逐项呈现成功、已采用、跳过、失败、未开始和未知。

### 发布与材料

当前草稿、当前验收版和历史送验版明确区分。范围、基线、MR、直接提交、回退、材料修订、SQL 顺序、配置冲突、冻结、验收、退回、终止、Tag 和归档在同一发布上下文中可追踪。验收和归档绑定当前清单 ID 与摘要，冻结后内容只读，历史修订仍可下载。

远端写入前展示目标、范围、冻结 SHA 和本人 GitLab 身份。未知结果先只读核实；只有已确认失败项才可通过新命令重试。关闭页面不承诺继续执行未开始项。

### 服务、主机与消息

连接可达、身份认证、具体业务权限和 Webhook 接收是不同结果。首选与兜底分别表达，凭证自然过期和诊断过时不得混为外部服务健康。

服务连接列表将编码放在独立列并提供复制按钮；说明收纳为名称旁的图标，通过 Tooltip 预览，点击可固定查看、滚动和复制全文。空说明不显示入口。详情编码与复制按钮垂直居中，保留按钮点击面积。创建成功提示的图标、正文和右侧关闭操作垂直居中；关闭按钮独立于正文布局，长文本可换行。Webhook 秘密表单首次进入对应页签才挂载，避免未访问的隐藏表单参与离开保护；访问后跨页签保留草稿和一次性 Token。

添加服务连接从列表打开 720px 右侧 Sheet，保留筛选和列表上下文，兼容 `?create=1` 与 `/admin/integrations/new`。采用“选择类型 → 连接信息 → 系统凭证”三步：类型使用两列单选卡片；鼠标选择仅显示细选中边框，键盘焦点使用卡片内部细虚线，避免叠加粗外环；名称、地址与说明整行，数据库主机和端口按宽窄列排列，端口复用数字输入框。公共 CA 按需展开，错误所在区域自动展开并聚焦。连接编码与凭证编码分别紧随对应名称直接展示，不折叠。系统凭证在第三步默认不勾选，按需展开认证字段；只有一个认证方式时显示文字。正文独立滚动，取消、上一步和唯一创建主操作固定在底栏。

空草稿关闭无需确认；更换已填写参数的服务类型需说明参数与认证材料清除范围，返回步骤保留草稿。连接与可选凭证统一在写入前校验，提交期间冻结编辑与重复操作。连接成功、凭证失败时锁定连接信息，只继续凭证操作或进入详情，明确关闭不会删除连接。结果未知保留本次编码，通过只读查询核实；未查到不能判定失败，不开放重复提交。创建成功不宣称已验证，不自动设置首选、兜底或 Webhook。

服务连接详情对 GitLab、Jenkins、OpenObserve、Elasticsearch、MySQL、PostgreSQL 使用统一页面容器，页头显示服务图标、名称与启停状态；启停与删除收纳到操作菜单。连接配置、归属凭证与支持的 Webhook 页签使用图标与文字，按能力和权限展示；无效页签回退到首个可用项。连接名称与编码直接展示，长地址整行换行；TLS 使用可读选项名称，公共 CA 显示配置状态。说明保留换行，长内容可展开并局部滚动，提示不使用负边距叠放。

编辑连接配置使用 720px 右侧抽屉，每次打开读取已保存配置及版本。名称后直接展示只读编码；HTTP 地址整行，数据库主机和端口按宽窄列排列，说明使用多行文本域。取消丢弃草稿，未保存离开需确认；版本冲突重新加载后保留草稿并展示当前配置供核对，结果未知只读核实，不自动重放。配置编辑和连接测试分别管理状态与错误；保存后刷新服务端诊断，按配置版本读取，测试时间按系统时区显示。

Webhook 区分连接停用导致的接收暂停与接收开关状态，未配置秘密不能启用接收。替换或生成秘密前说明远端 Hook 同步影响；生成固定切换为 Secret Token，保留接收开关。未保存秘密和一次性 Token 在详情内切换页签时保留，离开或刷新需提醒，离开详情后清除。秘密替换结果未知时不能通过“已配置秘密”状态推断成功，也不能自动重放替换。

公钥探测不等于信任，必须核对 SHA256 指纹后显式确认；地址或端口变化后需重新信任。SSH 测试不发送登录材料，凭证验证不执行命令。

主机列表不设置说明列；有说明的主机在名称旁显示信息图标，无说明不显示入口。图标悬停或键盘聚焦时通过 Tooltip 查看完整说明，点击后通过 Popover 固定查看；长说明局部滚动，支持选择、复制、Escape 关闭和焦点恢复，不影响表格行高或列宽。

共享页签的选中下划线绘制在容器内部，不产生纵向滚动条；鼠标选中不出现外围蓝框，键盘焦点用浅色底纹区分，系统强制颜色模式保留内部焦点轮廓。

主机详情使用统一页面容器，页头展示主机名称与启用状态；启用/停用、删除收纳到右侧水平三点的 shadcn/ui Dropdown Menu，删除项在底部分组并保留确认。主机配置、公钥、归属凭证页签带图标与文字，配置和公钥草稿在页签切换时保留，离开详情仍需未保存确认。编码、地址、端口、信任数量与说明在配置面板中展示，长值局部换行。编辑时名称与只读编码为第一行，地址与端口为第二行，说明独占一行使用多行文本域。

添加主机从列表工具栏打开 720px 右侧 Sheet 抽屉，列表筛选保持不变；保留“主机信息 → 首个凭证”两步与固定底部操作，支持仅创建主机。关闭未保存表单需确认，提交期间禁止重复操作；主机创建成功而凭证失败时只重试凭证，结果未知时先进入详情核实。兼容 `?create=1` 和 `/admin/remote-hosts/new` 入口。

凭证创建的确认步骤只展示名称、编码、认证方式、登录身份、到期时间和说明摘要，不回显密码、私钥或 Token。认证材料的保存后不可读取说明放在认证字段旁。保存失败只显示一处主要提示，字段错误就近说明，请求编号和错误代码收纳到“技术详情”；缺少重试时间时不显示虚构倒计时。凭证集合版本缺失或冲突时可重新加载列表，保留表单草稿并由用户再次确认保存，不自动重放写入；结果未知仍禁止重复提交。

钉钉机器人详情采用单列基本信息、机器人认证、最近测试分区，页头只展示名称、状态及操作菜单，启停和删除收纳到菜单。基本信息第一行并排名称与编码（附复制按钮），第二行并排创建与更新时间，第三行说明独占一行。最近测试面板右上角依次放刷新结果、发送测试，发送测试为主按钮；停用或执行中时禁用并按状态说明原因。新建表单说明放在最后，secret 命名为“签名密钥”。移除常驻功能提示，错误、未知结果及历史结果按实际状态展示，技术诊断默认折叠。

邮件、短信和钉钉保持独立页面与术语。真实测试明确外发，短信提示可能计费；受理不表示送达、已读或群成员可见。本地短信模拟明确标注未发送。

### 邮件配置

控制台侧栏菜单使用“邮件管理”，页面标题和面包屑使用“邮件配置”，保留 `/admin/email` 路由；SMTP 配置、邮件模板、发送日志 Tab 同时显示图标和文字。对象详情只保留对象标题。SMTP 详情顶部和面板内的业务操作统一收纳到右上角三点菜单，包括发送测试、编辑配置、替换认证、启停和删除。配置编码放在详情字段区并提供复制按钮；展示、菜单和错误恢复遵循第 6 节。

SMTP 新建和编辑使用宽抽屉，按基本信息、服务器连接、认证和发件身份分组；公共 CA 收纳在高级选项。普通编辑只展示认证摘要，用户名与密码通过独立“替换认证”操作更新。发件名称最多 20 项；删除默认名称前先选择其他默认项。字段关联、未保存保护与提交防重遵循第 6 节，提交期间禁用相关控件和关闭操作。

邮件模板使用内容与隔离预览双栏，保存、预览、返回与删除集中在顶部，长表单独立滚动；HTML 邮件预览保留白色邮件画布。草稿、预览失效和错误定位遵循第 6 节，删除需要目标明确的确认。

邮件模板的参数定义与预览样例遵循第 6 节结构化配置规则，支持文本、数字、布尔值、对象字段和数组元素定义；样例中的对象和数组使用独立 JSON 输入。邮件保留自身的参数类型与校验，不依赖短信模块的参数校验或业务组件。

发送测试带入当前配置或模板，区分选项加载、失败和无可用配置，选择器读取全部分页数据。附件逐项显示名称和大小并可移除。发送结果未知时锁定再次发送，提供读取结果和日志入口；无记录或最近一次记录不能单独证明本次请求未发送，需人工核实后再准备下一次发送。发送日志的高级筛选包含 SMTP 配置、邮件模板和操作者 ID，布局遵循第 7 节，展示日志保留期提示。发送日志支持按配置、模板名称选择筛选，删除对象的历史 ID 仍可保留；关闭日志详情恢复列表筛选。

### 短信管理

短信管理保留短信配置、短信模板、发送日志三个图文 Tab，切换与日志详情抽屉遵循第 6 节上下文保留规则。短信日志支持配置、模板名称和操作者筛选，并保留已删除对象的历史 ID。

短信配置资料与认证替换分开编辑，详情操作集中在更多菜单。模板采用编辑与预览双栏，保存、预览、返回和测试集中在随页面滚动保持可达的顶部；远端预览展示签名、模板 ID 和映射值，本地预览展示正文。参数定义、供应商映射及当次输入遵循第 6 节结构化配置、草稿和预览规则；短信参数始终按字符串处理。模板删除需明确确认。

发送测试带入当前配置或远端模板，选项读取全部分页并区分加载、失败和无可用项。提交后阻止直接再次发送；结果未知提供本次记录读取、日志入口和人工核实后的下一次发送准备，不自动重放。保持“可能计费”“受理不代表送达”和“仅模拟、未发送”的区别。

## 9. 桌面与操作验收

优先支持 1920×1080 桌面显示环境，以实际浏览器 CSS 视口验收；更大桌面和系统缩放作为补充复核。手机、小尺寸平板和明显小于目标的窗口不属于当前专项适配范围。既有降级可以保留，但不能为手机机械压缩复杂表格或牺牲桌面效率。

所有操作支持键盘与可见焦点；菜单支持方向键、Home/End 和 Escape，弹层关闭后恢复触发点。表格横向滚动限制在自身容器，长名称、路径、密钥状态和多权限来源不撑破整页。表单在低可用高度下允许滚动，主要操作保持可达。

动画只表达状态或空间关系，通常 120–200ms；右侧 Sheet 使用上述官方默认入场、退出时长；按已确认要求，全站动画和过渡不随 `prefers-reduced-motion` 关闭或缩短，包括刷新旋转、下拉、日历和高级搜索弹层。系统强制颜色模式保留系统边框和焦点色。浅深主题均需检查正文、辅助文字、禁用态、状态浅底、输入自动填充、Portal 和浮层。

视觉验收使用真实长内容，复核单栏与分栏、窄工具面板、长行和加载失败等适用场景。状态切换后检查内容的实际行为，例如换行是否消除长行溢出、图形是否完整可见、同步滚动是否对应同一段落；不能仅以按钮颜色或 DOM 属性变化判定功能正确。

自动化测试与实际浏览器视觉验收分别记录。构建和测试通过不代表真实视口中的布局、字体和主题已验收；浏览器连接失败等情况需明确记录未验证范围与原因，不以单元测试或旧截图替代。

## 10. 维护与验证

视觉定制顺序为：语义令牌 → 基础组件变体 → 平台组合布局 → 页面局部布局。不要在页面中连续覆盖库内部 DOM 或普遍使用 `!important`。共享组件保持基础能力一致，通过语义变体或配置适应不同任务；修改前检查全部使用位置，说明跨页面影响，超出已确认范围时先确认。业务相似不等于合并领域：邮件、短信、钉钉以及服务集成、远程主机仍保持独立请求与业务组件。

每次改动按范围检查真实计数、字段错误、pending 防重、未保存保护、版本冲突、未知恢复、浅深主题、键盘和桌面缩放。纯视觉变化更新本文；路由和构建变化同时更新 [前端实现](frontend.md)；业务、权限或接口变化同步所属领域契约。

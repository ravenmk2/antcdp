# UI 设计规范

项目与团队的下一阶段交互规则见 [项目与团队设计](projects-and-teams.md)，页面路由、快捷方式、表单、图标裁剪与危险操作确认详见 [详细设计第 7 节](projects-and-teams-detail.md#7-具体页面与交互)。基础功能已实现，尚未覆盖的验收边界见开发说明。

工作区侧栏项目/团队标题行的加号在桌面默认隐藏，悬停标题行或键盘焦点进入时显示；触屏设备常显。隐藏不移除布局占位或 Tab 焦点，按钮须具备可访问名称，避免布局跳动。

侧栏项目/团队分组仅显示标签与已固定快捷方式，不显示“查看全部项目/团队”；完整列表入口“我的项目”“我的团队”放入底部用户菜单，与“个人设置”“控制台”（管理员可见）依次合为一组；“外观”“退出登录”合为第二组，两组之间仅保留一条分隔线，桌面与移动端一致。工作区侧栏不再单列“个人设置”。点击进入工作区的本人参与列表，控制台全局管理导航保持独立。

正式快捷方式按账号在数据库保存并跨设备共享；项目、团队分组独立进行版本校验。旧页面保存发生冲突时重新读取并提示用户重做，不静默覆盖其他设备的排序。本地 HTML 原型存储仅用于演示。

工作区与控制台分离：工作区展示本人参与的项目/团队，侧栏支持按用户固定、取消和排序快捷方式；控制台管理全部对象及创建、归档、解散。加号表示添加快捷方式，不是创建对象。详细行为见上述设计第 7 节；当前实现边界见开发说明。

更新日期：2026-10-27。AntCDP = AI Native Team Collaboration & Development Platform（AI 原生团队协作开发平台）。视觉采用 暖色中性界面；提供浅色、深色和跟随系统三种外观，LOGO 使用小圆角正方形与蚂蚁头 SVG，陶土色与暖白色随主题互换。

## 1. 设计原则与来源

- 采用暖色中性背景、轻量侧栏、低阴影面板和克制的陶土色强调。浅色与深色共享布局、信息层级和交互；确保中文正文、表单与状态能够辨认。
- 页面围绕当前任务组织信息；顶部用于导航与返回路径，账号入口在侧栏底部。普通用户和管理员共享账号区域，管理能力集中到控制台。
- 主入口为“首页”，所有用户登录后默认进入首页。用户身份、菜单是否可见由权限决定，前端隐藏入口不代替后端授权。
- 一期只呈现已交付能力；项目、团队、工作流等后续功能不放占位菜单。

正式实现以本规范为基线。旧版原型仅作历史交互参考，不纳入 Git 或构建依赖；正式前端使用 tokens.css 统一主题变量，Element Plus 和功能组件复用相同语义色。

颜色和文字、图标或形状共同表达含义，不只依赖颜色。品牌展示色与正文操作色分开；浅色主操作使用墨色底、暖白文字，深色主操作使用暖白底、墨色文字。陶土色用于 LOGO 和品牌装饰，不用作常规主按钮底色。头像裁剪网格保留图像工具所需的固定白色引导线。

浅色采用暖白背景、深墨色正文与主按钮，配合中性灰阶及陶土品牌点缀。颜色与层次以本规范的语义变量为准。

深色使用五级表面：侧栏、主画布、卡片、输入框与弹窗、菜单浮层。保留中性主按钮、陶土色 LOGO 和专用功能状态色；辅助文字使用较亮的 `#8a8a8a`，确保表单说明可读。

深色分隔线与控件描边使用固定暖灰色，避免透明边框随底色变化而弱化。搜索框聚焦显示独立的焦点描边和外轮廓；输入框与选择器复用焦点语义色。深色菜单与弹窗使用控件级描边，菜单增加阴影并采用更亮的浮层底色。

主题入口在安装、登录、注册、维护页右上角；登录后收纳在用户菜单的“外观”二级菜单中。一级入口显示当前外观；桌面支持悬停或点击展开，鼠标离开入口后保留 300ms 关闭延迟，移入二级菜单时取消关闭；移动端支持点击展开。二级菜单提供浅色、深色、跟随系统三项，并以勾选标识当前选择。键盘右方向键、Enter 或空格展开二级菜单，左方向键或 Escape 返回一级；顶部导航不再单独显示主题切换。首次跟随系统；选择保存在本机 `antcdp.appearance`，允许的值为 `system`、`light`、`dark`。系统模式实时响应操作系统变化；其它浏览器标签页同步偏好变化。浏览器禁用存储时当前页面仍可切换，刷新回到系统偏好。该偏好不进入系统设置或账号数据库。

`theme-init.js` 在样式和 Vue 加载前设置根节点 `.dark` 与 `color-scheme`，避免主题闪烁；原生下拉、滚动条及 Element Plus 浮层跟随主题。主题样式覆盖自动填充、只读、禁用、错误、焦点、选中和悬停状态。系统强制颜色模式保留浏览器行为。

## 3. 中文排版

字体栈按原型记录：

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
```

字体使用系统可用字体，不依赖在线字体服务。中文使用正常字距；字重承担层级，避免大段粗体。用户名、ID、时间与技术值可使用 Cascadia Code / Consolas / monospace；数字优先等宽排列。

| 层级 | 大小与行高 |
| --- | --- |
| 全局正文 | 15px，1.65；段落 1.75 |
| 页面主标题 | 28px，1.4；小屏 26px |
| 区块标题 | 20px，1.5；设置小节 16px |
| 页面说明 | 15px；小屏 14px |
| 导航 | 15px |
| 表单 label / 输入 / 按钮 | 14px；输入行高 1.5，按钮 1.45 |
| 表格内容 / 用户主行 | 14px，约 1.5–1.55 |
| 表头、提示、状态和用户次行 | 13px，提示行高 1.75 |
| 数量与统计 | 29px，1.2；小屏约 27px |
| 登录表单标题 | 30px；小屏 29px |
| 页脚与次要标识 | 通常 13px；侧栏用户名和计数可用 12px |

新增主要内容不以 12px 承载。长中文提示允许自然换行；用户名可截断并提供完整值，密码与错误详情不能为了布局静默截断。

| 账号入口 | 侧栏底部，头像、显示名称、用户名；顶部仅保留一条细分隔线，入口不加外框或身份徽章，仅悬停和展开菜单时显示柔和底色；菜单向上展开并自动避让 |
| 面板 | 白底、1px 分隔边界、12px 圆角；间隔通常 18–26px |
| 常规弹窗 | 宽 560px，小弹窗 460px；内容可滚动 |
| 头像裁剪 | 宽 650px，图像操作区和预览区分列 |

已有顶部导航的首页、个人设置、概览、用户管理、系统设置和审计日志，不再重复展示内容区页面大标题及说明；主内容保留可访问名称。系统设置日常不显示重新加载按钮，加载或保存失败时提供重试或重新加载入口；其他页面操作使用紧凑右对齐操作行，业务区块标题保持。刷新使用统一环形箭头，只有主动点击刷新按钮才启动动画；首次进入、浏览器刷新和筛选查询不启动旋转，加载期间仍禁用重复点击。点击后动画至少持续 600ms，避免快速响应时看不清，数据不等待动画即可更新，长请求结束后停止；刷新图标按产品要求不受减少动态效果模式影响，其他动效仍遵循系统设置。审计页底部不再展示只读与敏感内容说明。

系统级导航：

- 工作区侧栏：`首页`，随后为项目、团队固定项分组。分组标题使用 12px 弱化文字，固定项图标统一为 19px，与首页文字起点对齐；组内紧凑、组间留白，不增加分隔线。空分组显示“尚未固定”。
- 控制台：`系统概览`、`项目管理`、`团队管理`、`用户管理`、`系统设置`、`审计日志`，按此顺序排列。
- 账号菜单：第一组为我的项目、我的团队、个人设置、控制台（管理员可见）；第二组为外观、退出登录。使用 Element Plus Dropdown 组件；外观为嵌套子菜单。控制台顶部提供“返回工作区”。
- 不显示“个人空间”、侧栏系统信息卡或运行状态卡；运行信息仅放系统设置的相应页面。
- 用户管理页保留状态页签及数量、搜索筛选、用户表格和分页；添加用户放在查询工具栏右侧，不单独占行；不显示标题说明、四个统计卡片、列表下方权限说明或查询栏管理员提示。
- “原型导航”、演示身份切换、数据重置与 LOGO 实验室属于原型工具，不进入正式产品导航。
- 控制台概览使用系统名称与更新时间的紧凑顶栏、四个账号指标，以及“最近操作 + 常用操作 / 访问策略”的主次分栏。指标包括全部、正常、禁用账号和管理员（含创始人）；前三项跳转到对应用户筛选，管理员仅展示数量，避免与排除创始人的身份筛选口径混淆。
- 最近操作显示真实最近五条记录，整行可打开审计详情，标题栏保留紧凑“查看全部”链接。常用操作提供添加用户、注册与会话、系统信息；访问策略显示注册状态、会话闲置有效期和系统时区，不展示没有检测依据的健康状态或占位功能。
- 概览指标卡使用 OverviewMetric，区块使用 OverviewSection；指标与快捷操作由类型化数组配置，主体网格容纳后续真实业务模块，不预建插件机制或未来模块空卡。1050px 以下主体改单列、指标两列；600px 以下侧边区块纵排。首次加载展示加载态；刷新失败保留最近成功数据并注明更新时间，允许重试。

新组件优先使用 4、8、12、16、20、24、32px 的间距；保留原型中已确认的 17、22、25、26px 等现有几何值，不为统一刻度重新改版。

## 5. 基础组件

### 项目与团队页面（2026-10-27）

- 工作区“我的项目”使用卡片网格：42px 中性图标容器、16px 名称及编码、最多两行摘要、成员数与本人角色；卡片高度与底部信息对齐。固定按钮独立于详情链接，取消固定不退出项目。正常状态弱化，归档保留文字标记。团队默认使用团队图标。
- “我的团队”使用横向列表：图标、名称/编码与摘要、成员数、本人角色、固定入口。控制台项目/团队统一采用表格，展示名称与编码、摘要、状态、成员数及详情入口；不展示接口尚未提供的管理员名单或示例数据。
- 列表使用状态页签、搜索、统一刷新和控制台创建按钮；沿用顶部导航标题，不增加重复大标题。“正常/已归档（团队为已解散）/全部”的数量按当前搜索及管理筛选从服务端读取，与分页总数使用相同范围，不取当前页长度。搜索遵循 600ms、回车立即提交、中文组词及旧响应失效规则。
- 详情合并图标、名称、编码、状态、摘要与操作。概览/成员/参与团队使用下划线页签；团队第三项统一称“加入项目”，显示调用者可见的已加入项目，不是新增授权按钮。编辑资料、刷新、退出、归档/恢复和解散放入更多菜单，详情头部仅保留固定与更多入口；刷新对所有可访问详情的用户可用，编辑仍受管理权限限制，沿用服务端能力与控制台入口限制。详情更多菜单宽度按最长菜单项内容自适应，不设置固定宽度或最小宽度；与用户菜单共用 7px 浮层内边距、42px 最小行高、10px/12px 菜单项内边距、17px 图标与 11px 图文间距，以及圆角和阴影；各操作均带图标，文字起点统一，菜单在触发按钮下方右对齐并自动避让视口。
- 概览为简介主区域和基本信息侧栏；正文使用可读宽度，不增加未实现业务模块。成员展示统一默认头像、名称/账号、来源和角色，最多直接展示两个来源，其余点击展开；直接成员的角色修改与移除放到行菜单，团队来源显示“团队管理”。当前成员接口未返回头像资料，不额外调用用户管理接口补全。
- 创建/编辑弹窗宽 660px、固定标题及操作区、仅正文滚动；名称与编码并排，编辑态编码只读；图标入口合并为“更换图标”，展开后选择默认、内置或上传裁剪；摘要、初始管理员及简介依次排列，简介支持编辑/预览。取消保留原数据，保存失败保留草稿，离页保护继续生效。
- 桌面卡片三列，超宽四列，中等宽度两列；650px 以下单列。团队元信息换行、详情基本信息下移、表单改单列；表格只在自身容器内横向滚动。页面沿用暖色中性双主题，菜单及弹窗复用语义色和焦点样式。

文本输入框的浏览器自动填充状态与手动输入使用相同主题面板底色及文字颜色；只读和禁用状态保留对应主题的弱化底色与文字，聚焦及错误继续由外层边框表达。统一覆盖 Element Plus 输入框（含弹窗）与原生搜索框，兼容 Firefox 和 Chromium 自动填充；系统强制颜色模式保留浏览器配色。保留密码管理器支持，登录使用 username/current-password，注册与新密码使用 new-password，显示名称使用 nickname；系统配置、代管资料和搜索字段显式关闭自动补全并提供稳定 name，但不依赖该属性控制视觉样式。

圆角通常为：控件 7px、菜单 9–11px、面板 12px、弹窗 14px、裁剪框 15px。层级按顶部导航 12、侧栏 15、菜单 55、弹窗 60、裁剪层 85、toast 100 组织，避免页面自行无限增加 z-index。

图标统一使用 SVG，圆端点和圆拐角，主要描边宽 1.65，常用图形 18–19px。箭头、关闭、更多、用户等操作均使用图标组件，不使用字符或 emoji 充当操作图标。纯图标按钮必须提供名称；装饰图形对辅助技术隐藏。

## 6. 品牌与头像

主 LOGO 使用 `web/public/logo.svg`：小圆角正方形，外框圆角半径为边长的 9.375%（48 单位视图中为 4.5），中央为圆脸与折角触角。双眼位于圆脸右上方，左低右高，近侧较宽、远侧较窄；眼睛弧度顺应右脸轮廓，触角根部、方向和远近大小表达同一球面朝向。轮廓根据确认稿转成矢量路径，保持比例，不叠加渐变或立体材质。

LOGO 固定使用陶土色 `#d97757` 与浅色主题画布的暖白色 `#faf9f5`，头部为实色填充。浅色主题使用 `logo.svg`：陶土色底、暖白色头部与触角，双眼为陶土色；深色主题使用 `logo-inverse.svg` 互换两色：暖白色底、陶土色头部与触角，双眼为暖白色。侧栏、登录、安装及欢迎图形直接显示相应双色 SVG，favicon 随外观选择同步切换。LOGO 不叠加半透明或滤镜，保证实色区域保持指定色值。正式资源只包含定稿 SVG，探索稿和预览截图留在 Git 外。

登录与注册页左侧只保留小尺寸品牌标识、主标题及留白；不展示轨道线和放大的占位方块。

常用尺寸：品牌色块 37px，列表头像 38px，侧栏头像 36px，个人资料头像 68px。没有上传图片时统一使用固定 SVG 用户图形和中性背景，不按身份改变底色；有图片时容器背景透明，无边框和阴影，图片采用 object-fit:cover 并由容器统一裁切圆角。裁剪预览同样不加装饰边框。

头像交互：

1. 选择 JPG、PNG 或 WebP，最多 2 MiB；非法文件给明确反馈。
2. 打开固定 1:1 裁剪层；支持拖动、键盘微调、1–4 倍缩放、90° 旋转、重置及重新选择。
3. 同时显示资料与导航尺寸的效果预览；确认后只更新当前表单草稿。
4. 保存资料后才替换正式头像，取消表单保持原图。输出为 256×256 PNG，正式后端仍需重新解码、校验与编码。

登录与注册页移除“连接人与工具，让开发更有序。你的开发协作空间，从 AntCDP 开始。”及表单底部英文全称；关闭注册时，登录页隐藏整行注册入口。侧栏不显示英文副标，公共布局不显示版权和协作标语页脚。个人设置不展示创始人保护说明块，保护规则保持不变。

## 7. 表单与错误

- 登录、注册、个人资料、普通/强制改密和管理用户表单共用字段错误映射与焦点定位。注册及管理用户将用户名和密码完整规则放在对应输入框下；显示名称、用户名格式、密码长度、确认密码不一致、用户名占用、当前密码错误、新旧密码相同和服务端已知字段错误就近展示，按页面顺序聚焦首个错误字段。输入时清除该字段旧错误；错误说明参与布局，不绝对定位，不遮挡后续控件。其他或未知字段/规则保留表单级提示及请求编号；失败保留输入，切页或关闭密码表单清空密码。
- 必填字段有 label 和必填标记，placeholder 仅举例；显示名称支持中文。用户名用于登录，个人设置只读。
- 管理用户弹窗宽 640px，限制在当前视口内；标题与底部操作区固定，仅正文滚动。头像区紧凑横排，桌面显示名称/用户名、密码/确认密码和两个身份选项分别并排；600px 以下改单列。错误提示不遮挡底部操作，创建、编辑与重置密码共享布局。底部操作区上下 16px、左右 24px 内边距，按钮间距 10px；弹窗样式通过限定类名的全局规则覆盖弹出层，避免页面 scoped 样式无法命中。
- 自主注册表单：显示名称、用户名、密码、确认密码；不出现邮箱或身份选择。
- 新密码至少 8 个 Unicode 码点、最多 72 个 UTF-8 字节。界面显示字节上限，前端和服务端按同一规则校验，不用 JavaScript 字符串 length 代替字符/字节计数，不强制字符类别组合。
- 提交过程中禁用重复提交，成功后显示明确反馈；失败保留非敏感输入并定位问题。密码、令牌不写入日志、URL 或正式前端 localStorage。
- 接口错误按 [API 契约](api.md) 的 error.code 处理，details 为数组。包含 field 的条目定位字段，其余条目展示在页面；只解释受支持的 code/context，未知错误回退到 message 和 request_id。
- 开关、资料、头像等编辑只在保存后生效；取消不写入设置或正式资料。系统设置按当前分类保存，显示未保存状态并提供撤销；切换分类、离页和刷新时保护未保存修改，保存过程中阻止切换。
- 侧栏、移动账号菜单和账号安全页的退出入口统一显示“确认退出登录”。取消或关闭确认框不调用退出接口；确认后撤销当前会话并返回登录页。处理中阻止重复触发，失败保留当前页面并显示错误。
- 删除用户要求输入用户名，明确“无法从界面恢复、用户名不可复用”；创始人和自身保护规则优先。
- 强制改密会话进入专门的改密流程；不能通过关闭弹窗、Escape 或导航绕过。正式前端使用独立受限页面，同时提供更新密码和退出登录入口，不显示可跳转至其他业务页面的导航；API 也执行同样限制。
- 空列表、搜索无结果、加载中、权限不足、服务不可用分别展示可理解的状态；数据库不可用不跳转到安装向导。用户和审计列表请求失败显示失败及重试入口，不显示搜索无结果；系统设置初次加载失败可原地重试。
- 安装向导采用居中双栏卡片，“欢迎 → 连接数据库 → 系统配置 → 创始人账号 → 完成”，其中三个配置步骤提交真实数据，不展示安装令牌；仅未安装时开放。连接检查要求空库，提交前再次核验；存在持久化安装锁时展示已安装或维护状态。
- 安装完成显示 5 秒倒计时，自动以 replace 导航进入 `/home`，同时保留“立即进入首页”按钮。离开页面取消倒计时；安装中、维护或服务不可用时不跳转。安装成功仅当前浏览器获得创始人会话。已安装系统再次访问安装页，直接按会话进入首页或登录，不重复倒计时、初始化或补发身份。

## 8. 响应式与可访问交互

| 宽度 | 规则 |
| --- | --- |
| 大于 1200px | 240px 侧栏、32px 内容边距，概览可多列 |
| 851–1200px | 224px 侧栏、30px 内容边距；1050px 以下概览统计和侧面板逐步减列 |
| 850px 及以下 | 抽屉导航；隐藏桌面侧栏底部账号入口，顶部使用移动头像入口；内容边距 22px |
| 600px 及以下 | 内容边距 17px，表单双列转单列；裁剪预览移到操作区下方，弹窗适应视口并可滚动 |

表格在容器内横向滚动，不把整页撑出视口。小屏保留“返回工作区”及账号操作。折叠偏好只影响桌面，移动抽屉状态不替代该偏好。移动抽屉打开后焦点进入关闭按钮、Tab 保持在抽屉内、背景不可交互且禁止滚动；Escape 或关闭按钮关闭后恢复触发按钮焦点，切回桌面解除限制，关闭状态的导航不可聚焦。

业务表格样式限定在 `.table-scroll` 内，不影响日期选择器。600px 以下的审计日期范围浮层固定在视口内，两个日历纵向排列，内容区可滚动且底部操作保持可达。路由切换默认回到页面顶部，浏览器前进/后退恢复保存的滚动位置。

所有可操作元素可通过键盘到达并有可见焦点；弹窗约束焦点并在关闭后返回触发元素。普通弹窗可取消，强制改密只有改密或退出。动效采用原型约 140–220ms 的轻微过渡，不依赖动画表达结果；正式组件尊重减少动态效果的系统偏好。

## 10. 正式前端落地

按 layouts、features、shared 划分，建立主题变量、基础控件、头像编辑、确认弹窗、错误映射与统一 API 客户端。Element Plus 作为控件基础，使用官方深色变量与本项目语义色映射；外观以本文为准。保留功能布局和组件几何：侧栏 240/224px、顶部 72px、首页欢迎卡片与快捷入口、登录页单色品牌插图、安装居中向导、用户筛选/表格及设置页分类布局逐页核对。

一期验收覆盖首页、登录/开放与关闭注册、安装、个人资料/安全、控制台概览、用户管理、系统设置和审计；同时检查管理员与普通用户、空结果、错误、窄屏、键盘、头像取消和强制改密。原型中的每页 6 条演示数据、固定演示口令与模拟数据库检查不是正式产品约束，正式分页与协议以 API 文档为准。

头像编辑在个人资料和管理员用户表单中使用相同组件：确认裁剪只生成上传草稿，保存表单才绑定；取消、切换账号页或关闭用户表单会丢弃未绑定草稿。裁剪弹窗支持拖动、滚轮/滑块缩放、90° 旋转、重置、重新选图和方向键微调（Shift 加速），同时显示资料与导航尺寸预览；读取或上传期间阻止重复提交。

审计列表保留原型的事件图标、只读表格和详情弹窗，关键词、事件类型、时间范围、清除筛选和刷新按钮在桌面同一工具栏，空间不足时自然换行；600px 以下搜索独占一行、事件类型与清除筛选及刷新同行，时间范围独占一行且标签置顶；不显示点击详情与时区说明文字，时间筛选和显示语义保持不变；使用真实游标分页，不显示演示总数。用户与审计列表均提供每页 10、20、50、100 条，默认 10；分别在本机 localStorage 的 antcdp.page-size.users / antcdp.page-size.audit 记忆选择。非法值回退 10，存储受限时保留当次页面选择；修改数量重置页码及审计游标。切换筛选回到第一页；详情包含事件代码、操作者和对象快照、时间、请求编号及经过白名单过滤的变更。概览的最近操作可打开相同详情，并提供“查看全部”导航。

用户与审计列表统一搜索行为：停止输入 600ms 后自动查询，Enter 立即查询并取消待执行的延迟查询；中文输入法组词期间及确认组词的 Enter 不发起查询，组词完成后再延迟查询。状态、身份、事件、时间范围与每页数量变化立即查询并重置页码或游标。两页均提供刷新和清除筛选；清除关键词及本页全部筛选（含审计时间范围），保留每页数量偏好并回到第一页，无筛选时禁用清除。输入开始即将旧请求标记为过期，只有最新请求能更新列表、数量、错误和加载状态；离页取消待执行查询。搜索和筛选不触发刷新旋转动画。

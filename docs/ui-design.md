# UI 设计规范

## 规范的适用方式

后续开发不要生搬硬套旧原型、截图或现有页面，也不要把某次验收的像素值当成永久标准。先明确用户任务、信息优先级、真实内容长度与设备条件，再选择布局、组件和密度。

本文区分三类信息：

| 类型 | 使用方式 |
| --- | --- |
| 产品与交互约束 | 保持权限、数据真实性、业务含义、保存/取消语义、错误恢复和可访问性。用户已确认的导航、文案和操作归属按其适用页面执行，最新明确要求优先；不能以视觉优化为由暗改业务行为。 |
| 视觉默认值 | 字号、间距、圆角、阴影、宽度、列数、断点和组件组合是设计起点。可按内容和设备调整，无需仅因偏离旧像素值再次确认；优先复用语义变量并保持同类操作一致。 |
| 当前页面示例 | 用于理解现状，不强制推广到新页面；被替代的方案不再约束开发。 |

下文的视觉尺寸均按第二类理解；产品协议中的字段上限、文件限制、权限条件及已确认的保存/搜索行为不因此放宽。品牌 LOGO 使用定稿资源。设计调整在上述桌面支持范围内优先验证真实内容、长文本、空/错误/加载状态、浅深主题和键盘操作，以清晰、可用和一致为验收依据，不要求与旧截图逐像素一致。

任务明确要求“保持现有 UI/UX 不变”时，以改动前的实际页面为基线保留视觉和交互；上述设计自由度不用于扩大该次重构的范围。

业务权限与接口分别见各模块文档；本规范维护导航、视觉与交互约束。

AntCDP = AI Native Team Collaboration & Development Platform（AI 原生团队协作开发平台）。视觉采用暖色中性界面；提供浅色、深色和跟随系统三种外观，LOGO 使用小圆角正方形与蚂蚁头 SVG，陶土色与暖白色随主题互换。

## 设计原则与来源

- 采用暖色中性背景、轻量侧栏、低阴影面板和克制的陶土色强调。浅色与深色共享布局、信息层级和交互；确保中文正文、表单与状态能够辨认。
- 页面围绕当前任务组织信息；顶部用于导航与返回路径，账号入口在侧栏底部。普通用户和管理员共享账号区域，管理能力集中到控制台。
- 主入口为“首页”，所有用户登录后默认进入首页。用户身份、菜单是否可见由权限决定，前端隐藏入口不代替后端授权。
- 只呈现已交付能力；项目与团队基础功能已上线，工作流、AI 执行等未交付能力不放占位菜单。

### 样式归属与维护

`web/src/styles/app.css` 管理语义变量、排版及全局交互样式。`components/ui` 维护基础控件、变体和焦点表现，`components/platform` 统一字段、列表、分页和浮层。功能页负责信息层级和局部布局。

## 颜色

浅色与深色共用语义变量名称。在 `web/src/styles/app.css` 中维护画布、卡片、浮层、文字、边框、主操作和焦点色。信息、成功、警告和危险状态使用各自语义变量，搭配可读状态文字。产品 LOGO 和服务图标保留品牌识别色。

`theme-init.js` 在样式和应用加载前设置根节点 `.dark` 与 `color-scheme`，避免主题闪烁；原生下拉、滚动条及浮层跟随主题。主题样式覆盖自动填充、只读、禁用、错误、焦点、选中和悬停状态。系统强制颜色模式保留浏览器行为。

## 中文排版

首选 MiSans，保留系统字体兜底：

```css
font-family: "MiSans", -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Microsoft YaHei UI", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
```

MiSans 使用官方 WOFF2 字符分片，构建时下载并校验 SHA-256，随前端产物发布；字体二进制和缓存不提交 Git。运行时从本站按需加载，不请求第三方字体服务。采用 `font-display: swap`，加载期间或失败时使用系统字体。包含 400、450、500、600、650、700 字重；官方静态资源不含 550，因此将 550–600 映射到 600 字形。登录页不展示字体署名及许可链接；原始许可协议继续随字体资源发布。中文使用正常字距；字重承担层级，避免大段粗体。用户名、ID、时间与技术值可使用 Cascadia Code / Consolas / monospace；数字优先等宽排列。

| 层级 | 建议大小与行高 |
| --- | --- |
| 全局正文 | 15px，1.65；段落 1.75 |
| 页面主标题 | 24px，约 1.4 |
| 区块标题 | 通常 16px；发布工作区主区块 18px，弹窗标题 20px |
| 页面说明 | 14px；时间、版本与次级上下文 13px |
| 导航与操作菜单 | 14px；项目身份 16px |
| 表单 label / 输入 / 按钮 | 14px；输入行高 1.5，按钮 1.45 |
| 表格内容 / 用户主行 | 14px，约 1.5–1.55 |
| 表头、提示、状态和用户次行 | 13px，提示行高 1.75 |
| 数量与统计 | 29px，约 1.2，按实际优先级使用 |
| 登录表单标题 | 30px |
| 页脚与次要标识 | 通常 13px；侧栏用户名和计数可用 12px |

新增主要内容不以 12px 承载。长中文提示允许自然换行；用户名可截断并提供完整值，密码与错误详情不能为了布局静默截断。

1920×1080 桌面工作界面以 14px 承载表格、表单和操作，13px 承载辅助信息；关键阶段与异常状态至少 13px。项目介绍等连续阅读正文保留 16px 与宽松行高。概览发布名称普通行使用 15px、待核实行使用 16px，以字重和位置补充层级。字号无需全部为偶数，但同类内容应收敛到一致规格，避免大量相近的小数字号。保留根字号和全局正文的现有设置，通过组件语义调整，不以全局缩放连带压缩间距、图标和点击区域。

### 桌面与操作验收

优先支持 1920×1080 桌面显示环境，将其作为布局、信息密度、字号与审美验收的首要基准。验收记录显示分辨率、系统缩放、浏览器缩放及实际可用 CSS 视口，不能将显示分辨率直接等同于扣除浏览器工具栏后的内容尺寸。2560×1440 等更大桌面及系统缩放作为补充复核；例如 2560×1440 显示器使用 120% 系统缩放、浏览器缩放 100% 时，可复核 2133×1200 及预留工具栏高度的 2133×1080 CSS 像素。

手机、小尺寸平板和明显小于目标的窗口不属于当前支持范围，不要求专项布局适配，也不作为发布验收门槛。现有响应式降级可以保留，不为小屏牺牲桌面的信息层级、布局比例和操作效率。本文其他小屏、窄屏及移动端条目描述既有降级行为，不构成额外支持承诺；后续如需支持，再单独明确范围。此范围调整不取消键盘、焦点、浅深主题及桌面缩放下的操作可达性要求，长内容与低可用高度仍允许必要滚动，不能裁掉字段、反馈或主要操作。

全局内容外层使用侧栏右侧的可用宽度，移除原有 1600px 上限与自动居中；桌面左右内边距默认 32px，2xl 断点起为 40px。页面标题、项目页签和业务正文默认共用左锚点；项目介绍阅读态按已确认的文档布局居中，其他正文不叠加居中容器或额外整体缩进。输入框、下拉框和描边按钮共用控件边框 token，默认状态保持安静，面板分隔线更轻；具体颜色与交互状态见[通用组件](#通用组件)。浮层关闭图标保留 44×44 CSS 像素点击区域。

内容宽度按任务决定，不使用统一最大宽度把整个应用居中收窄。数据表格、产品分支、仓库和交付工作区的外层不设最大宽度或自动居中，沿可用宽度展开。概览保留当前 1360px token 上限并左对齐，在此范围内按内容和空间形成自适应主次分栏，避免单条任务横跨整个 2K 屏幕；主任务优先，辅助列保持可扫描宽度，空间不足时顺序堆叠。阅读正文与表单单独限宽：Markdown 正文约 800–880px，简单表单约 640–720px，复杂双列表单约 960–1120px，既有表单按内容设置的宽度继续保留；除项目介绍阅读态居中外，这些限宽区域仍从页面左锚点开始，弹窗与抽屉按各自容器布局。卡片内部保留必要内边距，不将卡片内边距再叠成整个业务区的缩进。长表单允许正文滚动，底部操作保持可见；大屏首屏优先呈现当前主行动。

键盘用户可从侧栏前跳至正文。通过账号菜单进入页面时，焦点移至正文；鼠标切页不显示焦点轮廓，键盘按 Esc 收起菜单时保留账号按钮的焦点提示。安装向导换步后聚焦新标题，校验失败时聚焦错误字段。已设置系统名称时浏览器标题显示系统名称与当前页面或资源名，名称为空时仍显示 AntCDP。仓库批量创建先选默认来源，再逐个指定有例外的仓库。未收到同步或外发响应时显示待核对，提供读取快照、查看相应配置发送日志或机器人诊断的入口。SMTP 高级 TLS 默认收起，已有 CA 或字段错误时展开。

## 布局与导航

以下几何值为现有布局的参考默认值，按内容宽度与空间利用率调整；导航的入口含义和访问权限保持一致。

顶部路径栏只承担定位与返回。超过四级的桌面面包屑优先保留项目、产品分支和当前项，较远层级收入可键盘操作的上级菜单；窄屏优先保留最近两级。长名称可截断，但悬停或键盘聚焦可查看完整名称，原有链接与列表筛选恢复行为保持。

| 区域 | 参考默认值 |
| --- | --- |
| 桌面侧栏 | 固定左侧，宽 240px，视口高 100dvh；1200px 以下桌面宽 224px |
| 折叠侧栏 | 宽 76px，保留图标、头像及可访问名称 |
| 顶部导航 | 高 48px，暖底与正文一致，仅保留淡分隔线；13px 面包屑，当前项中等字重；侧栏切换图标 18px、点击区域 44px，左右边距与正文一致；不放桌面账号菜单 |
| 主内容 | 外层使用侧栏右侧可用宽度，桌面内边距 32px、2xl 起 40px；标题、页签、正文共用左锚点；概览与表单按任务单独限宽并左对齐，项目介绍阅读态整组居中 |
| 账号入口 | 侧栏底部，头像、显示名称、用户名；顶部仅保留一条细分隔线，入口不加外框或身份徽章，仅悬停和展开菜单时显示柔和底色；菜单向上展开并自动避让 |
| 面板 | 使用主题面板色、细分隔边界和适量圆角；当前常用 12px 圆角、18–26px 间隔 |
| 常规弹窗 | 宽 560px，小弹窗 460px；内容可滚动 |
| 头像裁剪 | 宽 650px，图像操作区和预览区分列 |

已有顶部导航的个人设置、系统概览、用户管理、系统设置、审计日志、项目与团队列表、服务集成及各归属凭证入口、远程主机及各归属 SSH 凭证入口，不再重复展示内容区页面大标题；主内容保留可访问名称。项目内的当前工作/项目记录、项目介绍空状态及编辑页、关联仓库、未选中产品分支时的产品分支、项目与产品分支发布列表，以及邮件/短信模板创建页同样移除页面大标题和对应留白，操作与必要业务信息紧凑排列。首页保持现状；团队、连接、主机、产品分支、发布、配置及模板的资源名称标题、产品分支切换入口、业务区块标题、弹窗标题、异常提示及用户 Markdown 正文标题保留。系统概览与项目概览不显示主动刷新按钮，加载失败时保留重试入口；项目概览无摘要时不渲染空页头或占位留白。系统设置日常不显示重新加载按钮，加载或保存失败时提供重试或重新加载入口；其他页面操作使用紧凑右对齐操作行，业务区块标题保持。刷新使用 Lucide `RotateCw` 单箭头圆环，只有主动点击刷新按钮才启动动画；首次进入、浏览器刷新和筛选查询不启动旋转，加载期间仍禁用重复点击。点击后动画至少持续 600ms，避免快速响应时看不清，数据不等待动画即可更新，长请求结束后停止；刷新图标按产品要求不受减少动态效果模式影响，其他动效仍遵循系统设置。审计页底部不再展示只读与敏感内容说明。

当前系统级导航与页面安排（导航含义及用户确认的入口归属继续执行，具体视觉组织按任务优化）：

- 工作区侧栏：`首页`、`我的项目`、`我的团队`为常驻主导航，随后仅为“关注项目”分组。分组标题使用弱化文字，固定项图标与主导航协调对齐；组内紧凑、组间留白。空分组提供选择常用项目并关注的入口，不展示固定团队或团队快捷方式管理入口。
- 控制台：`系统概览`之后按组织与协作（项目、团队、用户）、服务与连接（服务集成、远程主机、邮件、短信、钉钉机器人）、平台维护（系统设置、审计日志）分组。
- 账号菜单：侧栏底部向上展开，第一组为个人设置，以及管理员专属的“控制台”或“返回工作区”（按当前位置切换）；第二组为外观、退出登录。外观为嵌套子菜单。“我的项目”“我的团队”由主导航承载，菜单中不重复。控制台和工作区的顶部均不另设切换入口。
- 不显示“个人空间”、侧栏系统信息卡或运行状态卡；运行信息仅放系统设置的相应页面。
- 用户管理页保留状态页签及数量、搜索筛选、用户表格和分页；添加用户放在查询工具栏右侧，不单独占行；不显示标题说明、四个统计卡片、列表下方权限说明或查询栏管理员提示。
- 控制台系统概览以最近操作为主，辅助区保留快捷入口与访问策略，不再展示全部、正常、禁用账号及管理员等用户统计卡片。不展示系统名称、更新时间与刷新按钮整行，加载失败时保留重试入口。
- 最近操作显示真实最近五条记录，整行可打开审计详情，标题栏保留紧凑“查看全部”链接。添加用户、注册与会话、系统信息等快捷入口继续保留，但不增加“常用操作”标题或副标题；访问策略显示注册状态、会话闲置有效期和系统时区，不展示没有检测依据的健康状态或占位功能。
- 系统概览按实际内容组织自适应主次分栏，空间不足时将辅助区顺序放到主内容下方，不预建未来模块空卡。首次加载展示加载态；刷新失败保留最近成功数据并注明更新时间，允许重试。

间距优先使用 4、8、12、16、20、24、32px 等共享尺度，按内容节奏、对齐和触控需要调整。

### React 导航与浮层

- 侧栏菜单和账号入口悬停时使用浅一层的中性底色。当前项使用稍深的中性底色和中等字重，折叠时由图标底色识别。键盘焦点使用独立轮廓。底部账号显示名称与 `@用户名`，菜单展开时延续其悬停底色。
- 业务内容区标题直接衔接工具栏或业务内容，省略通用页面介绍。详情中的资源标识、分支、用户填写的摘要和实际状态，以及安装、恢复及危险操作的必要提示按任务展示。
- 全平台操作提示以柔和语义色填满提示块，配合同色细边框、可读文字和图标。成功使用绿底对勾，进行中使用蓝底时钟，需核对使用琥珀底警示，失败使用红底叉号。深色主题使用深色语义底和浅色文字。发送测试依据服务端结果区分已受理、拒绝与结果未知。提示在视口中央短暂显示，不占用内容布局、不抢焦点。3 秒后消失，新提示替换旧提示，切换页面或 URL 页签即清除。错误、结果未知和需要操作的反馈留在对应操作区。
- 状态使用小圆点及明确文字。绿色表示可用、已受理或已确认成功，蓝色表示开始或执行中，琥珀色表示部分完成、结果未知或需核对，红色表示失败、拒绝或凭证过期。停用、归档及仅已记录为中性。审计列表和详情共用状态口径，发送测试完成事件本身不证明投递成功。
- 分页器左侧提供每页条数选择，有可靠总数时显示“共 N 条”，右侧使用 `‹ 1/10 ›`。仅提供游标时，箭头间显示“本页 N 条”；前后一页以已访问的游标和服务端下一游标为准。可用箭头悬停或键盘聚焦时显示轮廓，首末页禁用方向保持可辨。
- 单选下拉使用低对比细线箭头，强制颜色模式沿用系统控件。创建服务连接时按后端实际能力平铺图标、名称和用途，支持搜索与键盘选择。审计列表按时间、事件、操作者和操作对象展示，时间筛选按需展开，整行和详情按钮均可进入详情。

- 桌面侧栏提供展开和收起两种密度，开关放在侧栏顶部；收起后保留常显展开按钮，不依赖悬停发现。移动端在顶栏保留打开导航按钮，抽屉内提供关闭入口。复用浏览器偏好 `antcdp.sidebar-collapsed`。展开态的导航、关注项目和账号菜单使用 14px 标签，辅助信息为 13px；按已确认的桌面紧凑方案，主导航与关注项目整行点击高度均为 40px，保留完整焦点轮廓。收起后保留可聚焦的图标、名称提示和账号入口。移动端侧栏以完整抽屉打开。
- 工作区主导航常驻“我的项目”“我的团队”，下方仅展示“关注项目”，不展示固定团队分组或管理团队快捷方式入口。工作区与控制台切换统一放入侧栏底部用户菜单：管理员在工作区看到“控制台”，在控制台看到“返回工作区”；普通用户不显示管理入口。侧栏顶部不设置独立切换区域。账号菜单同时保留个人设置、外观与退出，桌面展开、折叠及移动端使用相同入口归属。控制台按组织协作、服务连接、平台维护分组，消息模块继续各自独立。项目使用“关注项目／取消关注”动作及星标，表示个人关注列表，不自动订阅消息；团队仍保留首页固定语义。首页显示按账号隔离的本标签会话最近访问和正式关注／固定项；最近访问只记录名称、类型和路由，不作为实时状态来源。
- 项目外的顶栏展示当前路由的资源层级；项目内使用统一项目导航，对象正文保留必要的短路径。上级可点击，末级标记为当前位置，窄屏将较远祖先收入上级菜单。已访问列表在同一标签页按用户恢复筛选。弹窗取消、向导上一步及仓库目录上一级在各自操作区域内处理。
- 列表按筛选、结果、分页顺序布局，把主要创建操作放在对应列表的工具栏。短确认把目标和后果放在同一区域，底部单独排列取消及执行动作；长表单继续分区。弹窗外壳负责四角裁切，正文独立滚动。

## 通用组件

尺寸和形态为默认建议；键盘支持、字段语义、危险操作说明和状态反馈是交互要求。

| 组件 | 默认外观与交互要求 |
| --- | --- |
| 按钮 | 普通按钮高至少 40px、7px 圆角；主操作使用中性强调色：浅色墨色底与暖白文字，深色暖白底与墨色文字，危险确认使用危险色及对应前景 |
| 图标按钮 | 图形通常 18px，点击范围独立于图形大小；按触控和键盘使用需要留足目标范围，不照搬旧页面约 30px 的点击框 |
| 输入框 | 高 44px、7px 圆角；登录表单 46px；label 在上，错误与帮助在下 |
| 数据库连接表单 | 按连接地址、数据库和凭据组织字段；可在桌面组合相关短字段，窄屏改为单列。标签和列边界对齐，测试按钮与错误提示留足间距 |
| 表格 | 单元格 14px、上下约 14px；表头 13px；用户头像、显示名称及用户名形成两行信息 |
| 页签 | 高约 57px；活动文字与底部线使用主色，数量采用浅底小标签 |

| 开关 | 34×20px，滑块位置和颜色共同表达状态，使用 role=switch 与 aria-checked |
| 下拉菜单 | 主题浮层色、细边框、适量阴影；宽度随内容和上下文确定，账号菜单当前约 242px 不作为其他菜单的下限；支持方向键、Home/End 与 Escape |
| 弹窗 | 头部标题/说明、正文、底部操作区；取消在左、确认在右，确认对话框按钮间距 10px，窄屏允许换行；危险操作明确写出对象 |
| 提示 | 字段问题紧邻控件；页面级问题在页面展示；成功反馈可使用视口中央的短暂提示 |

输入框、多行编辑区、原生和自定义选择器、描边按钮共用 `--control-border`：浅色默认 `#CBC8BF`、深色默认 `#56544D`；悬停使用 `--control-border-hover`（浅色 `#A6A193`、深色 `#79766B`）。不再用透明度混色导致同一工具栏边框深浅不同。面板与分隔线继续使用 `--border`（浅色 `#E3E1D9`、深色 `#3C3B34`），层级弱于可操作控件。聚焦或展开状态优先于悬停；错误字段保持错误色，禁用和只读状态不显示悬停强调。系统强制颜色使用系统边框与焦点色。

单行文本框、搜索框和多行编辑区共用独立焦点色：浅色主题为石墨暖灰 `#403D35`，深色主题为浅暖灰 `#C4BFB2`。聚焦时仅改变 1px 边框颜色；错误字段聚焦时保留错误色，系统强制颜色模式使用系统焦点轮廓。

文本输入框的浏览器自动填充状态与手动输入使用相同主题面板底色及文字颜色；只读和禁用状态保留对应主题的弱化底色与文字，聚焦及错误继续由外层边框表达。统一覆盖输入框（含弹窗）与原生搜索框，兼容 Firefox 和 Chromium 自动填充；系统强制颜色模式保留浏览器配色。保留密码管理器支持，登录使用 username/current-password，注册与新密码使用 new-password，显示名称使用 nickname；系统配置、代管资料和搜索字段显式关闭自动补全并提供稳定 name，但不依赖该属性控制视觉样式。

圆角通常为：控件 7px、菜单 9–11px、面板 12px、弹窗 14px、裁剪框 15px。层级按顶部导航 12、侧栏 15、菜单 55、弹窗 60、裁剪层 85、toast 100 组织，避免页面自行无限增加 z-index。

通用 UI 图标、项目/团队内置图标与登录页节点图形统一使用 Lucide（`lucide-react`），通过共享语义映射按需导入 SVG 组件，圆端点和圆拐角，以 Lucide 默认 2px 描边作为视觉起点，常用图形当前为 18–19px；描边、尺寸与留白按实际页面效果调整，不将这些数值作为优化限制。项目入口使用文件夹图形；内置资源图标保留既有键值及上传图片优先规则。产品 LOGO 与外部服务品牌资源保持独立，未知服务使用插头图标。箭头、关闭、更多、用户等操作均使用图标组件，不使用字符或 emoji 充当操作图标。纯图标按钮必须提供名称；装饰图形对辅助技术隐藏。

## 品牌与头像

主 LOGO 使用 `web/public/logo.svg`：小圆角正方形，外框圆角半径为边长的 9.375%（48 单位视图中为 4.5），中央为圆脸与折角触角。双眼位于圆脸右上方，左低右高，近侧较宽、远侧较窄；眼睛弧度顺应右脸轮廓，触角根部、方向和远近大小表达同一球面朝向。轮廓根据确认稿转成矢量路径，保持比例，不叠加渐变或立体材质。

LOGO 固定使用陶土色 `#d97757` 与浅色主题画布的暖白色 `#faf9f5`，头部为实色填充。浅色主题使用 `logo.svg`：陶土色底、暖白色头部与触角，双眼为陶土色；深色主题使用 `logo-inverse.svg` 互换两色：暖白色底、陶土色头部与触角，双眼为暖白色。有系统名称时，侧栏图标为 40px，保留现有品牌排版；名称留空时，图标为 32px，AntCDP 字号为 24px，并省略副标题。侧栏、登录、安装及欢迎图形直接显示相应双色 SVG，favicon 随外观选择同步切换。LOGO 不叠加半透明或滤镜，保证实色区域保持指定色值。正式资源只包含定稿 SVG，探索稿和预览截图留在 Git 外。

常用尺寸：品牌色块 37px，列表头像 38px，侧栏头像 36px，个人资料头像 68px。没有上传图片时统一使用固定 SVG 用户图形和中性背景，不按身份改变底色；有图片时容器背景透明，无边框和阴影，图片采用 object-fit:cover 并由容器统一裁切圆角。裁剪预览同样不加装饰边框。

头像交互：

1. 选择 JPG、PNG 或 WebP 原图，客户端不按原始文件大小或 4096px 边长拦截；解码失败给明确反馈。原图仅在浏览器本地处理，裁剪为 256×256 PNG 后再检查 2 MiB 上传限制。
2. 打开固定 1:1 裁剪层，画布挂载即绘制首帧，不依赖首次缩放；支持拖动、键盘微调、1–4 倍缩放、90° 旋转、重置及重新选择。
3. 同时显示资料与导航尺寸的效果预览；确认后只更新当前表单草稿。
4. 保存资料后才替换正式头像，取消表单保持原图。输出为 256×256 PNG，正式后端仍需重新解码、校验与编码。

登录与注册不展示口号或英文页脚；注册关闭时隐藏登录页的注册入口。侧栏不显示英文副标。个人设置不展示创始人保护说明块，保护规则仍生效。

## 登录与注册窗口

登录与注册采用居中的左右双栏窗口，左侧保留品牌及项目、代码、无嘴巴机器人三个插图节点，右侧为表单；不展示口号、英文页脚或会话时长说明。桌面参考宽度 1000px、分栏比例 42:58；窄屏保留品牌并改为单栏，页面随内容滚动。浅深主题通过 auth 语义变量统一设置背景和插图表面。

注册用户名提示精简为单行“3–30 位小写字母、数字、_ 或 -”，完整规则可悬停查看，格式错误仍就近说明。密码日常提示为“至少 8 个字符。”，字符与字节上限校验保持原有规则。注册关闭时隐藏登录页创建入口，并在注册页展示关闭状态；字段错误、重复提交保护、密码清理和强制改密跳转保持原逻辑。

## 表单与错误

- 登录、注册、个人资料、普通/强制改密和管理用户表单共用字段错误映射与焦点定位。注册及管理用户提供用户名和密码规则，简要提示与完整规则按表单信息量组织；显示名称、用户名格式、密码长度、确认密码不一致、用户名占用、当前密码错误、新旧密码相同和服务端已知字段错误就近展示，按页面顺序聚焦首个错误字段。输入时清除该字段旧错误；错误说明参与布局，不绝对定位，不遮挡后续控件。其他或未知字段/规则保留表单级提示及请求编号；失败保留输入，切页或关闭密码表单清空密码。
- 必填字段有 label 和必填标记，placeholder 仅举例；显示名称支持中文。用户名用于登录，个人设置只读。
- 管理用户弹窗按表单内容确定宽度，640px 是当前桌面参考值，并限制在视口内；标题与底部操作区保持可达，正文超高时滚动。相关字段在空间充足时并排，窄屏改单列；错误提示不遮挡操作。创建、编辑与重置密码共享布局原则，底部保留舒适的留白和按钮间距。弹窗样式需覆盖实际挂载的浮层，避免页面 scoped 样式无法命中。
- 自主注册表单：显示名称、用户名、密码、确认密码；不出现邮箱或身份选择。
- 新密码至少 8 个 Unicode 码点、最多 72 个 UTF-8 字节。界面显示字节上限，前端和服务端按同一规则校验，不用 JavaScript 字符串 length 代替字符/字节计数，不强制字符类别组合。
- 提交过程中禁用重复提交，成功后显示明确反馈；失败保留非敏感输入并定位问题。密码、令牌不写入日志、URL 或正式前端 localStorage。
- 接口错误按 [API 契约](api.md) 的 error.code 处理，details 为数组。包含 field 的条目定位字段，其余条目展示在页面；只解释受支持的 code/context，未知错误回退到 message 和 request_id。
- 开关、资料、头像等编辑只在保存后生效；取消不写入设置或正式资料。系统设置按当前分类保存，显示未保存状态并提供撤销；切换分类、离页和刷新时保护未保存修改，保存过程中阻止切换。
- 侧栏、移动账号菜单和账号安全页的退出入口统一显示“确认退出登录”。取消或关闭确认框不调用退出接口；确认后撤销当前会话并返回登录页。处理中阻止重复触发，失败保留当前页面并显示错误。
- 删除用户要求输入用户名，明确“无法从界面恢复、用户名不可复用”；创始人和自身保护规则优先。
- 强制改密会话进入专门的改密流程；不能通过关闭弹窗、Escape 或导航绕过。正式前端使用独立受限页面，同时提供更新密码和退出登录入口，不显示可跳转至其他业务页面的导航；API 也执行同样限制。
- 空列表、搜索无结果、加载中、权限不足、服务不可用分别展示可理解的状态；数据库不可用不跳转到安装向导。用户和审计列表请求失败显示失败及重试入口，不显示搜索无结果；系统设置初次加载失败可原地重试。
- 安装向导采用居中双栏卡片，“欢迎 → 连接数据库 → 系统配置 → 创始人账号 → 完成”，其中三个配置步骤提交真实数据，不展示安装令牌；仅未安装时开放。连接检查要求空库，提交前再次核验；存在持久化安装锁时展示已安装或维护状态。
- 安装完成显示 5 秒倒计时，自动以 replace 导航进入 `/home`，同时保留“立即进入首页”按钮。离开页面取消倒计时；安装中、维护或服务不可用时不跳转。安装成功仅当前浏览器获得创始人会话。已安装系统再次访问安装页，直接按会话进入首页或登录，不重复倒计时、初始化或补发身份。

## 响应式与可访问交互

支持范围以[桌面与操作验收](#桌面与操作验收)为准，小屏不列入当前专项适配及发布门槛。断点根据内容何时开始拥挤确定。下表记录已有响应式方案，可随组件结构和容器宽度调整，不表示各宽度均需支持；桌面验收重点是信息可读、操作可达及无整页横向溢出。

| 参考宽度 | 默认方案 |
| --- | --- |
| 大于 1200px | 240px 侧栏、32px 内容边距（2xl 起 40px），概览在限宽内自适应分栏 |
| 851–1200px | 224px 侧栏、约 30px 内容边距；概览主次分栏按内容逐步堆叠 |
| 850px 及以下 | 抽屉导航；账号操作保留在抽屉底部；内容边距 22px |
| 600px 及以下 | 内容边距 17px，表单双列转单列；裁剪预览移到操作区下方，弹窗适应视口并可滚动 |

表格在容器内横向滚动，不把整页撑出视口。小屏在侧栏底部用户菜单中保留“控制台”或“返回工作区”及账号操作，管理入口仍按管理员权限显示。折叠偏好只影响桌面，移动抽屉状态不替代该偏好。移动抽屉打开后焦点进入关闭按钮、Tab 保持在抽屉内、背景不可交互且禁止滚动；Escape 或关闭按钮关闭后恢复触发按钮焦点，切回桌面解除限制，关闭状态的导航不可聚焦。

业务表格的排版与横向滚动限定在列表容器内。日期筛选与浮层在窄屏保留可达的输入和操作区。

所有可操作元素可通过键盘到达并有可见焦点；弹窗约束焦点并在关闭后返回触发元素。普通弹窗可取消，强制改密只有改密或退出。动效保持轻微、及时，不依赖动画表达结果；140–220ms 可作为普通过渡的起点。一般动效尊重减少动态效果的系统偏好；主动刷新图标的例外见[布局与导航](#布局与导航)，不推广为其他动效的规则。

| 账号区域 | 底部用户菜单提供个人设置、外观、退出登录；管理员在工作区看到“控制台”，在控制台看到“返回工作区”；账号安全位于个人设置内 |
| 状态与操作 | 正常、已禁用、启用、禁用、删除用户、重置密码、保存更改 |

表单占位文案使用通用的操作提示，例如“设置用于登录的用户名”，不出现开发者姓名、用户名或环境信息。安装向导侧栏仅保留标题与步骤，不展示数据归属宣言。

界面不再用“站点”指代系统。现有 API 的 site_name、部署配置和设置键 site.name / site.timezone 保留技术命名，不因中文文案调整而重命名。字段与领域一致性见 [设计入口](README.md)。

## 前端维护与验证

按功能边界组织应用布局、features 和 shared，复用主题变量、基础控件、头像编辑、确认弹窗、错误映射与统一 API 客户端。本地基础组件统一读取主题变量。后续开发先梳理任务与数据，再决定页面布局和组件组合；优化比例、密度和信息层级，避免为了复刻旧页面而保留不合适的几何值。

复用应复用语义和可用性，不要求所有页面长得一样。在桌面支持范围内检查关键任务能否完成、长内容是否清晰、操作是否可发现、状态是否真实，以及双主题和键盘体验。纯视觉调整同步相关规范即可，业务、接口和存储契约仅在受到影响时更新；不要求同步不可版本化的本地原型。

头像编辑在个人资料和管理员用户表单中使用相同组件：确认裁剪只生成上传草稿，保存表单才绑定；取消、切换账号页或关闭用户表单会丢弃未绑定草稿。裁剪弹窗支持拖动、滚轮/滑块缩放、90° 旋转、重置、重新选图和方向键微调（Shift 加速），同时显示资料与导航尺寸预览；读取或上传期间阻止重复提交。

审计列表提供事件标识、只读记录和详情入口。关键词、事件类型、时间范围、清除筛选和刷新按使用顺序组合，空间不足时自然换行；小屏优先保证搜索和日期控件可用，不照搬原型工具栏行数或断点。不显示重复的点击详情与时区说明文字，时间筛选和显示语义保持不变；使用真实游标分页，不显示演示总数。用户与审计列表均提供每页 10、20、50、100 条，默认 10；分别在本机 localStorage 的 antcdp.page-size.users / antcdp.page-size.audit 记忆选择。非法值回退 10，存储受限时保留当次页面选择；修改数量重置页码及审计游标。切换筛选回到第一页；详情包含事件代码、操作者和对象快照、时间、请求编号及经过白名单过滤的变更。概览的最近操作可打开相同详情，并提供“查看全部”导航。

用户与审计列表统一搜索行为：停止输入 600ms 后自动查询，Enter 立即查询并取消待执行的延迟查询；中文输入法组词期间及确认组词的 Enter 不发起查询，组词完成后再延迟查询。状态、身份、事件、时间范围与每页数量变化立即查询并重置页码或游标。两页均提供刷新和清除筛选；清除关键词及本页全部筛选（含审计时间范围），保留每页数量偏好并回到第一页，无筛选时禁用清除。输入开始即将旧请求标记为过期，只有最新请求能更新列表、数量、错误和加载状态；离页取消待执行查询。搜索和筛选不触发刷新旋转动画。

## 工作区任务入口

首页优先展示“我的项目”“我的团队”两个任务入口和真实的已固定项目、团队；欢迎语使用“欢迎回来，{显示名称}。”，显示名称缺失时回退用户名；首页不重复展示系统名称、控制台入口或底部账号链接。移除入口副标题、区块说明与重复引导，只保留必要的空状态、加载和错误提示。固定项加载、失败重试、空状态分别呈现，不把加载失败解释成没有项目。未参与的用户通过明确说明了解加入方式，不展示虚构统计或动态。

快捷方式弹窗分为已选项（显示数量、支持排序）和可添加项，项目保存后同步首页及侧栏；团队已保存偏好继续保留，但不在侧栏展示。不重复展示说明文案。项目卡片优先展示名称与摘要，名称允许换行；身份和状态同时保留，编码弱化，固定按钮保持独立操作。列表空状态提供清除筛选，管理员无数据时可创建。以上为当前任务布局，后续按真实内容和设备条件继续调整。

控制台项目管理与团队管理不再展示“仅显示无有效管理员”筛选行；前端不再附带该筛选条件，后端查询能力保留。

清除筛选按钮统一使用 Lucide `FunnelX` 图标，保留“清除筛选”的可访问名称与悬停提示，以及原有禁用、显示条件和清除行为。常规刷新按钮仅显示图标，保留“刷新”的可访问名称和悬停提示；菜单内刷新项仍保留文字便于识别。必要的权限来源、字段规则和危险操作后果继续保留。

## 项目、团队与产品分支

### 项目与团队页面

以下记录当前页面方案；卡片/列表组合、信息排列和尺寸可结合后续任务优化。用户明确确认的“加入项目”用词、详情编辑/刷新收纳到更多菜单、菜单按内容自适应继续作为当前交互要求，按对应页面保持一致。

- 工作区“我的项目”当前使用卡片网格：中性图标容器、名称及编码、摘要、成员数与本人角色；尺寸和摘要展示行数根据容器与内容调整，保持卡片节奏和底部信息对齐。关注按钮独立于详情链接，取消关注不退出项目。正常状态弱化，归档保留文字标记。团队默认使用团队图标。
- “我的团队”使用横向列表：图标、名称/编码与摘要、成员数、本人角色、固定入口。控制台项目/团队统一采用表格，展示名称与编码、摘要、状态、成员数及详情入口；不展示接口尚未提供的管理员名单或示例数据。
- 列表使用状态页签、搜索、统一刷新和控制台创建按钮；沿用顶部导航标题，不增加重复大标题。“正常/已归档（团队为已解散）/全部”的数量按当前搜索及管理筛选从服务端读取，与分页总数使用相同范围，不取当前页长度。搜索遵循 600ms、回车立即提交、中文组词及旧响应失效规则。
- 项目使用下文的统一项目导航与任务层级。团队保留独立固定入口，“加入项目”显示可见关联项目。详情更多菜单按内容宽度布局，各项保留图标及可访问名称，右对齐并自动避让视口。
- 团队概览保留简介主区域和基本信息侧栏；项目概览使用上述任务布局，两者不机械共用同一种内容结构。成员展示统一默认头像、名称/账号、来源和角色，来源较多时折叠并可展开查看全部，展示数量按行宽确定；直接成员的角色修改与移除放到行菜单，团队来源显示“团队管理”。当前成员接口未返回头像资料，不额外调用用户管理接口补全；该接口限制不等于未来禁止支持真实头像。
- 项目创建、团队创建/编辑和项目基本资料弹窗按字段和视口确定宽度，660px 是当前桌面参考值；标题和操作区保持可达，正文超高时滚动。名称与编码可在空间充足时并排，编辑态编码只读；图标入口合并为“更换图标”，展开后选择默认、内置或上传裁剪。创建时的摘要、初始管理员及简介按填写流程组织，团队简介保留编辑/预览；已有项目的介绍通过“介绍”页签整页编辑，不放入基本资料弹窗。取消保留原数据，保存失败保留草稿，离页保护继续生效。
- 卡片根据可用宽度和最小可读内容宽度自动增减列，不把当前三/四/两列及 650px 断点作为所有页面的模板。空间不足时团队元信息换行、详情基本信息下移、表单改单列；表格只在自身容器内横向滚动。页面沿用暖色中性双主题，菜单及弹窗复用语义色和焦点样式。

### 项目任务层级与长篇介绍

项目范围页面共用位于应用顶栏的项目身份与导航，包含集成凭证和 SSH 凭证子页。桌面项目切换器、六项导航和更多操作合为一行，替换全局面包屑栏及正文内重复的大项目标题；导航依次为“概览、发布、产品分支、仓库、介绍、设置”。小尺寸线性图标配合可见文字，选中态用文字与陶土色下划线表达。项目名称为可搜索切换入口，完整名称、编码和返回项目列表可在选择器中读取。长名称截断保留全文可访问性；空间不足时项目身份与导航分两行，导航自身横向滚动，禁止缩小点击区域或把整个页面撑宽。对象详情保留短上级路径和当前对象标题，返回恢复进入时的列表筛选与分页，旧书签继续有效。

概览以“当前工作”为主标题，先显示结果待核实的发布，再显示进行中的发布，产品分支与关联仓库放次要资源区。去重仅针对已经展示的记录，服务端总数保持真实并明确其包含待核实项；不能用分页预览推断项目健康或全量异常。产品分支资源称“未归档产品分支”，主干绑定异常按对象显示。没有进行中发布时提示准备下一次发布，并明确允许纯材料发布、环境按需配置；归档项目突出历史记录。普通成员得到查看入口，推进阶段与仓库关联继续遵守独立权限。摘要仅在有内容时显示，刷新置于标题工具区。

发布使用可选名称作为主标题，名称为空时回退当前版本号；名称存在时版本号和产品分支为次级上下文，避免回退场景重复版本。发布阶段与结果待核实等异常分别显示，统一阶段用语。详情首先给出当前对象、阶段和下一步操作，Tag、仓库范围、基线与历史按需展开。创建发布的必要 Tag 前缀和发布资料在连续表单中完成，失败保留草稿和已完成步骤，结果未知先核实。项目设置保留基本资料、成员、团队授权、Git 分支规则和访问凭证分类；Git 分支规则默认只读摘要，显式进入编辑。旧成员、团队、Git 分支模型书签继续定位对应分类。

从概览或项目发布列表发起创建时，取消选择产品分支或关闭创建抽屉均返回原入口，并恢复筛选与分页；返回地址只接受同项目的概览或发布列表，移除创建标记，避免再次自动弹出。项目列表、产品分支列表和详情使用相同的待核实口径，发布阶段与异常并列。归档产品分支的发布列表和详情显示只读原因，保留查看设置及有权限时的恢复入口；所属项目也归档时明确需先恢复项目，不再显示可以立即开始发布的提示。

项目介绍阅读态使用浅暖灰画布和柔和白色正文表面，深色主题对应深灰画布与略亮正文；正文与右侧目录作为整体居中，无目录时正文单独居中；正文含内边距最大约 60rem，桌面内边距 40–48px，按内容自然展开，不强行撑高短文。不加阴影，淡化边界与圆角。阅读态移除编辑按钮，编辑入口位于设置 → 基本资料 → 项目介绍，沿用管理权限和归档限制；空内容为可管理用户保留编写入口。一级标题适度收敛，代码块使用轻量语言/复制工具栏。多标题时右侧提供约 13rem 的粘性目录，只有零或一个标题时隐藏目录；当前位置通过细竖线和文字强调。标题锚点与阅读位置恢复保持不变。滚动超过一屏显示右下角 44px 悬浮返回顶部按钮，回到顶部后隐藏；提供提示、键盘焦点，遵循减少动画设置，键盘触发时焦点返回正文。长 Markdown 的表格和代码块局部横向滚动，代码支持复制；不执行原始 HTML、不嵌入图片。编辑态铺满项目页签下方的剩余可用视口，顶部单一工具栏依次提供编辑/预览/分栏分段切换、字节计数、保存状态及取消/保存；选中模式使用独立表面、边框与轻阴影。正文与预览各自滚动，工具栏始终可达，100 KiB UTF-8 上限不变。保存成功返回阅读态，阅读布局及目录保持不变。保存仅修改 description，并保留初始 ETag、失败草稿、未保存导航保护和结果未知核对。

普通交互控件的键盘焦点使用单层 2px 暖灰轮廓；文本输入与选择器使用下文的单层细边框，不叠加 ring。输入边框和错误边框保持清晰；仅键盘或输入编辑等需要时显示焦点。浮层通过鼠标关闭不强制触发键盘光环，Esc 关闭仍恢复可见焦点；强制颜色模式使用系统焦点色。语义信息状态可保留蓝色，蓝色不再作为普通控件装饰。

### 产品分支与环境

业务对象统一称“产品分支”，不简称“分支”；具体仓库引用称“Git 分支”，主干字段称“主干 Git 分支”，环境字段称“绑定 Git 分支”。英文领域标识保留 `variant`。

项目产品分支采用分页列表与独立详情，搜索名称/编码、状态筛选与页码在返回列表后保留；默认正常、标准版优先，管理操作收纳在更多菜单。进入产品分支详情后保留紧凑项目身份和主要导航，顶部面包屑保留“项目 / 产品分支 / 当前产品分支”；详情名称即切换入口，使用可搜索、分页加载的产品分支选择器。既有链接仍可直接访问；具体业务规则见 [产品分支设计](project-variants.md)。

产品分支详情将“环境”“仓库与分支”“发布”作为稳定导航。进入具体发布后收起产品分支导航，保留项目导航、面包屑和返回发布列表。主干创建从仓库工作区进入，创建记录为次要入口；当前子视图保存在 URL。头部显示产品分支身份、主干、仓库数量和设置，归档与绑定异常按真实状态独立提示。环境名称进入查看，删除置于更多操作；创建主干仍须选择仓库、设置来源并经过远端预检，环境只支持绑定和校验。

分支列表注明当前目标分支，创建页也保留“校验所选分支”。过时校验在状态列显示“需重新校验”，历史分支和原结果收纳在详情中；刷新提示明确只加载本地结果，不能暗示已重新查询远端。

产品分支、环境、仓库与分支、创建记录、批量创建来源/预览/结果以及范围选择/预览均复用用户管理的公共面板和表格样式：工具栏、内容区域、计数分页共用一个外框；搜索、状态分段筛选、清除、刷新与创建操作按实际能力展示，不添加虚构计数。表头、正文及行内操作左对齐，字体、单元格内边距、分隔线与悬停效果使用平台表格组件；名称/编码采用主次信息，状态使用语义色标识，常用操作直接显示，其他操作进入更多菜单。完整提交与诊断信息按行展开查看。分页使用统一总数、10/20/50/100 条选择及前后翻页；有界批次展示真实总数。加载、错误、空结果在内容区域展示，加载或错误不显示零条计数。窄屏保留表格结构，仅在表格容器内横向滚动；项目详情导航自身横向滚动，按钮不撑开页面。

产品分支设置、环境新建及编辑采用右侧抽屉。查看环境和编辑环境在同一抽屉内切换，取消回到查看，保存后展示最新结果；关闭和离开页面保护未保存修改。抽屉标题注明所属产品分支，底部操作固定，仅内容区滚动；窄屏铺满可用宽度。表单资料按内容双列排列，说明和仓库范围占整行；环境默认继承、产品分支默认全部仓库，只有自定义时展示勾选器。“按规则匹配（高级）”按需展开，已有规则默认展开并标明数量，手动与规则仍取并集。仓库路径、分支与提交 ID 可换行。产品分支主干与环境绑定字段展示项目当前类型的启用状态、匹配方式和命名规则；服务端校验失败映射到对应字段，明确区分名称未分类、规则歧义、类型不符及格式错误，不以笼统提示替代原因，也不自动修改项目规则。创建预览、执行与历史结果保持独立操作弹窗，长内容滚动、底部操作可见。

### 邮件、短信与钉钉

控制台侧栏不展示“消息管理”分组标题，[邮件](email-management.md)、[短信](sms-management.md)、[钉钉](dingtalk-management.md)作为平级入口分别进入独立页面；不使用共用消息类型切换页面或跨模块业务组件。三者可使用平台 UI 基础组件/主题，功能状态和专属样式分别管理。三类页面与功能样式已独立实现。

消息模块列表内容区不重复展示“邮件”“短信”“钉钉机器人”大标题，由侧栏和面包屑标识当前位置；内容直接从功能页签或列表工具栏开始。具体配置/模板详情保留资源名称以便识别。桌面主要表单采用 1120px 上限双列布局，简单认证/记录对话框采用 840px；窄屏收为一列，超长内容仍允许滚动。1920×1080 常规表单优先完整呈现操作区，不以隐藏溢出内容换取无滚动。

消息模块表单对话框按内容加宽；1920×1080 下优先通过双列分组减少垂直滚动。发送测试将目标、发件身份及附件与消息内容并列，常见表单和结果尽量完整展示，底部操作保持可见。宽度随视口收缩，窄屏恢复单列；长内容、浏览器缩放或小高度下允许必要滚动，不裁剪字段和错误反馈。

消息模块输入框和文本域聚焦使用单层细描边，弹窗滚动区保留 4px 内边距，避免原生选择器、按钮及强制颜色模式下的键盘焦点轮廓被边缘裁剪。列表刷新复用平台 RefreshButton，仅展示带可访问名称的图标；主动点击时旋转，加载期间禁用，动画与其他管理页面一致。

## 服务集成与远程主机

### 外部服务集成

本节描述当前交互语义。领域与权限见[服务集成设计](service-integrations.md)，接口见[服务集成 API](service-integrations-api.md)。布局继续按任务和内容选择，不把历史截图作为模板。

- 控制台模块仍叫“服务集成”，其中的记录统一叫“服务连接”；按钮使用“添加连接”“编辑连接”“删除连接”。目录展示名称、code、服务类型、说明和管理启停，不把启用标成健康。
- 仅展示已实现的服务类型及能力。GitLab、Jenkins、数据库、日志服务使用各自表单；邮件、短信、钉钉是各自独立的已实现模块，见[设计入口](message-management.md)，不放入服务类型菜单，不增加未实现的占位入口。
- 类型筛选、名称/code/说明搜索和启停筛选共享；状态写入 URL，进入详情后返回保留。创建始终使用“选类型 → 连接信息 → 首个凭证”三步向导，类型使用可搜索的紧凑双列选项单选，窄屏单列，选项区域独立滚动；列表保留全部/具体类型入口；窄屏改为带标签下拉。
- 列表与详情保留 code 值和复制入口，不显示“编码”前缀；详情配置表单不重复展示只读 code。
- 创建向导前两步只保存本地草稿，最后提交。首个系统凭证常显名称与编码，不自动设首选或兜底；末步提供“创建连接和凭证”与“仅创建连接”两个按钮，不使用跳过开关；连接成功而凭证失败时保留已创建连接，重试仅提交凭证，也可进入详情继续。返回保留输入，更换类型清空不兼容配置和认证材料并提示，关闭清除秘密草稿。
- 连接和凭证的名称与“编码（可选）”桌面并排、窄屏单列；编码用于程序引用，鼓励自定义，保留留空自动生成和创建后不可修改的契约。添加凭证分“基本信息 / 认证信息 / 有效期与状态”页签，编辑资料仅展示基本信息与有效期/状态，替换认证信息仍为独立操作；校验失败定位对应页签。操作按钮固定在弹窗底部，秘密独占整行，有效期空值表示不设到期时间。连接向导与凭证对话框不展示辅助说明段落、字段帮助与示例文案；保留字段标签、实际连接摘要、错误反馈、空状态和必要的操作确认。
- 连接详情按任务组织“连接配置 / 系统凭证 / Webhook 接收设置”，未支持入站的类型不显示 Webhook 页签。公共资料及服务配置属于同一聚合，可一次保存；分区编辑时也使用同一连接版本，不能用旧的主表/配置两套版本悄悄覆盖彼此。
- 连接 code 创建可选、之后只读；实例地址和公共 CA 等配置仅管理员可见。TLS 放入高级区，不提供跳过证书校验。“测试已保存的连接”不提交草稿、不暗用兜底凭证；验证结果与保存状态分开。
- 系统、项目、个人凭证共用表单和权限判断。项目/个人从有限连接目录进入，只维护本归属的访问凭证，不显示连接内部地址、其他归属数据或Webhook 设置项。归档项目只读。
- 凭证名称和 code 合并展示，独立显示状态、有效期、首选和兜底。“首选”属于当前归属，“兜底”只针对系统凭证且代表缺失时回退；同一凭证可同时有两个标记。新建不自动设置标记。
- 普通资料编辑与“替换认证信息”分开。后者根据服务同时提交完整认证方式、身份和秘密，不能通过旧秘密占位保留材料。关闭/取消清除秘密草稿，不存浏览器持久化存储，保存后仅显示已配置状态。
- Webhook 页签直接展示此连接唯一的接收地址、验证方式、秘密配置状态、启停和最近诊断，无接入点列表、添加/删除入口、名称、说明或 code。
- 新连接默认关闭 Webhook，先导入/生成秘密、配置远端 Hook，再显式开启接收。不提供事件筛选或项目 ID 配置，相关规则由消费方管理。
- 验证方式变更与秘密替换原子提交；生成/导入不隐式启用。轮换提示针对当前连接，说明所有使用此连接地址的远端 Hook 都须更新，其他连接不受影响。Token 生成后一次性展示，已有秘密不可再次读取。
- 接收地址可复制；诊断区分未接收、配置已变化和已接收未分发。未认证请求不写最近摘要，配置保存错误另行提示。Webhook 设置不展示消费规则编辑器，禁止显示“工作流已触发”的成功提示或模拟执行入口。
- 连接停用提示其阻断出站验证和所有入站，但子开关保留；删除连接要求凭证已清空且无项目仓库引用，提示 Webhook 设置和秘密一并删除、接收地址失效，远端 Hook 需自行移除。
- 诊断按独立接口加载，未加载显示“查看记录”，确认 latest=null 才显示“尚无记录”；旧配置结果标注已过时。诊断不使编辑表单版本失效。自然过期前端计算，不能把已配置/未过期等同于外部权限有效。
- 412 保留非秘密草稿并提示重新加载，秘密重新填写；失败不静默覆盖。在桌面支持范围内保证键盘与浅深主题可用；既有窄屏降级将相关短字段改单列，列表信息自然换行。

### 凭证标识维护

各服务共用凭证 code 字段：创建时可选，留空由服务端生成无短横线的 UUID；同服务类型跨连接和归属唯一。列表展示 code，编辑时只读，名称和说明仍可修改。GitLab 不再显示令牌类别选择器，用途由说明表达。格式错误保留草稿，重复 code 提示冲突而不展示其它归属的信息。

### 服务集成工作台

服务列表采用类型菜单与结果区两栏，类型菜单不提供搜索、独立滚动，类型来自真实服务能力和连接数据，不展示未实现服务占位。即使只有一种服务，仍显示“全部服务”和对应类型入口及数量；窄屏使用带标签的类型下拉。类型写入 URL 查询参数，刷新、进入详情和返回时保留；名称/code/说明搜索与启停状态可组合，空结果提供清除筛选。

服务连接采用紧凑表格，名称和详情头部使用服务图标，优先呈现名称、code、说明、类型和启停。控制台详情顶部使用“服务集成 → 服务类型（如 GitLab）→ 连接名称”三级面包屑，前两级分别返回全部连接和该类型列表；详情区不再显示“返回连接列表”或名称上方的服务类型文字。个人凭证详情沿用类型层级，项目凭证保留项目上下文层级。详情保留连接/凭证/Webhook 接收设置导航；Webhook 使用连接内的一份共享配置，不提供接入点集合。系统、项目和个人共用类型筛选，权限按新领域契约执行。连接高级 TLS 折叠，凭证 code 用等宽字体。

凭证支持名称/code/说明搜索及可用、即将到期（7 天内）、已过期、已停用、未配置秘密筛选；这些是记录状态，不代表外部服务验证成功。code 提供复制入口。行内保留更多菜单，编辑、替换认证信息、验证、首选、兜底和删除均收纳其中。未加载验证结果显示“查看记录”，请求确认无记录后才显示“尚无记录”。创建表单按基本资料、认证材料、有效期分组；普通编辑与完整认证替换保持独立。

控制台项目管理、团队管理和用户管理的列表工具栏沿用审计日志的搜索框样式、控件对齐和间距，依次排列搜索、状态分段筛选、其他筛选、清除筛选、刷新与创建操作；窄屏自然换行。状态分段控制器保留各页原有三个选项、计数和默认值，使用浅色底座（深色主题对应表面色）、圆角边框，选中项使用独立表面色与轻微阴影，支持键盘切换。工作区沿用当前状态筛选选项与真实计数，表格列标题保持一致。

控制台项目与团队列表创建按钮固定靠工具栏右侧；底部沿用用户列表布局，左侧显示总数及每页数量，右侧显示上一页、当前页/总页数与下一页。空结果保留统计和禁用的翻页入口，加载中禁用分页操作；更换每页数量回到第一页。工作区列表共用此分页布局，详情成员分页保持原行为。

工作区“我的团队”沿用同一列表工具栏、状态分段控制器及总数/每页数量/翻页布局，保留横向团队列表及原有权限，不提供控制台专属创建入口。“我的项目”同样使用与控制台项目列表一致的工具栏、表格面板和分页，列为项目、成员、状态、我的身份、操作，不再使用卡片与独立摘要；保留查看和关注操作、我的项目数据范围与权限，创建和“没有可用管理员”筛选仍仅限控制台。详情成员分页保持原行为。

统一列表工具栏下的加载与空状态和底部分页使用连续的表面色与左右边框，形成完整面板；空状态不重复工具栏已有操作。结束状态（归档/解散）或搜索无结果时提示调整筛选，不显示加入团队或创建资源的引导。

### 服务连接编码与详情操作

连接 code 的界面文案统一为“编码”。列表图标右侧按名称、编码两行排列；详情编码位于名称下方，使用 13px 次要色等宽字体。长编码单行省略，提供完整值提示和复制按钮。详情移除顶部“编辑资料”，资料统一在连接配置中编辑；更多操作使用轻量省略号按钮，菜单项带图标，删除使用危险色。GitLab 地址支持 HTTP、HTTPS、自定义端口及子路径；HTTP 时禁用高级 TLS 的 CA 输入并保留原值。

### Jenkins 服务集成

Jenkins 与 GitLab 共用服务连接和凭证导航，连接配置包含实例地址与公共 CA，支持部署子路径。Jenkins 凭证创建/认证替换填写用户名和 API Token；用户名可展示和搜索，Token 保存后不可读取。Jenkins 不显示 Webhook 页签。连接测试显示 HTTP 可达与服务识别，凭证成功明确标注“身份认证成功；构建权限未验证”；代理拒绝、重定向、身份不匹配和异常响应给出具体原因。

对话框底部使用可换行的 flex 布局和显式 12px gap；嵌套按钮组也必须自行设置 gap。向导底部保持取消在左、步骤和提交操作在右，窄屏换行后保留行列间距。

服务集成列表不显示管理用途说明，添加连接位于筛选栏右侧；关键词输入采用约 300px 紧凑宽度，窄屏占满一行。行尾使用右箭头进入详情，保留可访问名称、悬停背景与键盘焦点反馈。

服务集成列表顶部内边距收紧为 16px，类型导航与列表区域不再额外叠加顶部外边距。列表、详情及凭证列表的编码复制共用组件：复制成功后原位显示绿色勾，2 秒后恢复复制图标；再次复制重新计时，失败显示错误而不显示成功状态，卸载时清理计时器。

凭证列表沿用用户管理表格的工具栏、14px 内容字号、行内边距、底部计数与操作布局；添加凭证位于筛选栏右侧。编辑、更多操作和查看记录提供悬停/键盘焦点反馈，弹出菜单项带语义图标。服务连接目录在现有完整目录接口上进行前端展示分页，默认 20 条，可选 10/20/50/100 条；先筛选再分页，筛选或每页数量变化回第一页，URL 保留查询和页码，详情返回恢复。该分页不减少接口读取量。

服务连接表格与分页页脚置于同一面板，页脚复用用户表格的内边距，仅保留表格与页脚之间的一条分隔线，避免独立表格外框与页脚上边框叠加。凭证行内只保留更多操作入口，“编辑凭证”作为菜单首项，带编辑图标。

凭证列表始终按“筛选工具栏 → 内容区域 → 计数页脚”排列。加载、错误、无凭证、无筛选结果与表格互斥呈现在内容区域；该区域顶部统一一条分隔线，空状态不另加虚线边框或外边距。加载及错误时不显示计数，避免误报 0 条。

服务集成连接测试、系统/项目/个人凭证验证与 Webhook 接收结果共用语义文字色：成功绿色、失败红色、暂不支持黄色、未知或无记录中性灰色。按最终诊断状态判色，HTTP 可达不覆盖认证失败。历史结果优先显示黄色“历史结果”与灰色原结果，避免误认为当前有效；时间、身份、事件和项目保持次要色。Webhook 已验证接收为绿色，“未分发工作流”为次要色；连接与凭证成功继续保留未验证身份、具体业务权限未验证等边界说明。复用浅深主题变量，保留文字含义和紧凑布局。

连接详情页顶部只保留外层 20px 留白，详情自身不再叠加顶部内边距；标题去掉上边距，页头不叠加底部内边距，页头与连接页签间距为 12px，页签与内容间距为 20px。空描述不渲染占位段落；长名称和描述自然换行，列表及其他页面间距不受影响。

### OpenObserve 与 Elasticsearch 表单

服务类型选择增加 OpenObserve、Elasticsearch，沿用连接和凭证的创建、编辑、首选、兜底与诊断交互。OpenObserve 默认组织预填 default，可编辑；密码或服务账号 Token 均以秘密输入框录入。Elasticsearch 创建首份凭证及替换认证时提供“用户名与密码 / API Key”选择，API Key 仅显示完整 encoded 值输入框，切换认证方式清空旧身份与秘密。无认证集群可跳过凭证创建，连接详情明确提示无需空凭证。两类服务均不显示 Webhook 页签。

OpenObserve 验证成功显示认证及默认组织列表访问通过，明确日志查询权限未验证。连接测试不携带凭证，HTTP 可达不等同认证成功；权限不足、组织/接口不存在和认证失败分别给出受控原因。所有秘密保存后不可查看。

服务连接列表的空状态在原有面板内展示，不叠加虚线框及外边距；样式仅作用于连接列表。所有服务类型的连接配置默认以字段和值展示，不渲染输入组件；通过配置标题旁的“编辑”原位切换表单，保存成功返回只读视图，失败保留草稿，取消直接丢弃草稿。切换详情页签保留编辑状态，离开详情时沿用未保存提示。只读视图保留已保存连接测试及诊断结果，编辑期间隐藏测试；高级 TLS 折叠展示 CA 状态及公共证书纯文本，未启用 TLS 时说明配置不生效。

### 远程主机

独立入口、页面和业务组件，与服务集成对齐筛选、分页、编码复制、凭证表单、更多菜单和诊断的交互语义。固定 SSH 协议，创建使用“主机信息 → 首个凭证”；主机配置默认只读，编辑原位切换，页签切换保留草稿。详情不展示额外“返回主机列表”按钮、页头说明文字或停用提示横幅；启用/停用及删除放入更多菜单，顶部面包屑负责返回。系统凭证与主机公钥分开管理，个人和项目入口仅维护对应归属凭证。公钥须通过可信来源核对后显式信任，探测不自动保存；身份不匹配阻止认证。具体契约见[远程主机管理](remote-hosts.md)。

### 远程主机独立模块与列表面板

远程主机的页面、凭证面板、配置、公钥及诊断组件独立于服务集成维护，保持统一视觉与交互语义。主机列表参考用户管理：搜索、状态筛选和添加按钮置于表格面板顶部，表格/空状态位于中间，分页在底部，共用一个外边框。窄屏允许工具栏换行。保留详情更多菜单以及既定无额外返回按钮、无页头说明、无停用提示横幅的规则。

## 项目 Git 仓库

详见[项目 Git 仓库关联](project-repositories.md)。控制台管理、工作区只读；已关联列表全宽，添加面板采用懒加载组导航与分页仓库列表，仓库不放树内。搜索显式标注全连接/当前组范围，跨页选择保留，切换连接需确认清空。窄屏使用组选择与面包屑；状态含空、错误、加载、归档、缺少首选凭证，浅深主题与键盘焦点可辨。

仓库列表：每行只保留详情与更多入口，同步和解除收进菜单，解除项危险色并以分隔线区分。默认隐藏 checkbox 列；系统管理员通过“批量操作”进入选择模式，展示已选数量、同步信息、更多及退出入口；退出清空选择。未选时禁用同步和更多，解除收于更多菜单；批量解除必须展示目标完整路径清单并确认。组导航采用当前层列表、完整路径和上一级返回，适配按需查询。

关联选择器采用固定高度双栏：左侧当前层组目录与组搜索，右侧路径面包屑、仓库搜索、分页结果；列表独立滚动，页码和提交栏始终可见。查看已选在右侧内容区切换，不叠加长清单撑高弹窗；窄屏将组导航折叠。变更查询立即清空旧结果并丢弃过期响应，提交错误独立显示且保留选择。

仓库操作列固定操作区宽度、操作表头与按钮组整体居中，仓库列的表头与内容左对齐，其余列的表头与内容均居中。详情采用仓库标题/路径、双列元信息、HTTP/SSH 克隆地址切换及复制反馈、同步状态分区；长路径换行。批量操作包含同步信息，解除仍以危险色收在更多菜单。同步对话框展示总进度及逐项结果，失败项保留选中供重试，运行期间禁止关闭以避免误解为取消任务。

同步窗口仅结果列表滚动，标题、总进度和底部操作保持可见；滚动区预留滚动条槽和右侧内边距，错误与长路径换行。默认按列表中最前的未完成项跟随进度，避免并发完成顺序造成跳动；手动向上滚动暂停，可点击继续跟随，完成后保持位置。同步完成仍处于选择模式，成功项取消选中、失败项保持选中。

仓库列表使用固定列布局：选择列 48px、全选与行内 checkbox 水平垂直居中，操作列 132px，仓库列承接剩余空间；窄屏保持横向滚动。仓库名称前使用 24px 中性灰仓库书册/分支线性图标，无背景底板，在每行信息块内垂直居中。详情保留按钮样式和点击区域。

## 项目产品分支发布

发布列表与详情使用独立内容区，从面包屑可返回所属产品分支。列表支持版本和状态筛选，返回时保留分页。列表页头与详情摘要沿用应用卡片、文字和边框主题变量；按钮沿用公共组件配色。浅色、深色与跟随系统共用布局。详情摘要展示版本、Tag、仓库数、有效 MR 数和材料数量；发布说明以一级标题起笔时可用作摘要标题。所有计数取自当前发布。

桌面交付工作区沿全局可用宽度展开，使用左侧工作区、右侧阶段面板，左边缘与项目标题及页签对齐；内部发布说明按阅读需要限宽，不将整个工作区居中收窄。本次变更、交付材料、发布说明、验收与归档四个入口使用小线性图标，可用原有链接直达，显式 URL 选择优先；未显式选择时，草稿或准备阶段默认打开本次变更，验收或归档阶段默认打开验收与归档。范围与基线由次级展开区承载，缺基线集中提示；没有登记 MR 的仓库仍属于完整版本范围，不为其生成空变更卡，也不将其标成“无变化”。

发布主区以实际登记的 MR 与直接提交为中心，支持仓库、状态与文字筛选，已移出与已回退记录可追溯。全局添加变更先选择范围内仓库，再添加 MR 或补录直接提交；候选 MR 自动加载并以列表呈现，保留按编号纳入已在外部合并 MR 的入口。候选搜索仅覆盖已加载记录，不能表示跨仓库或全部远端搜索。零 MR 是正常状态，允许仅交付配置、SQL 或其他材料，但仍遵守全量范围、基线、冻结与归档校验。

创建入口与草稿阶段面板提前说明：可先保存草稿，开始发布仍需至少一个范围仓库及全部基线。范围为空时提供检查产品分支仓库范围入口；系统管理员可直接进入控制台关联仓库，项目管理员得到联系系统管理员的准确说明。材料版本冲突后在原抽屉保留草稿，按需展示已保存版本对照，显式核对后才继续编辑，避免关闭重开导致草稿丢失。

阶段推进动作始终位于同一阶段面板：确认范围并开始、核对版本与材料、冻结并送验、验收、归档。核对结果首先显示待处理问题，额外提交提供补录入口，完整仓库与 SHA 清单按需展开。核对结果绑定发布版本与路径；发布更新后旧结果失效，已打开的送验抽屉也不得继续提交旧核对结果。远端结果未知时优先核实，保持并发版本、幂等和权限处理。材料按数据库脚本、对象存储文件、配置和附件分组，非空组展示数量，统一从「添加材料」选择类型；收起时显示文件名、修订、SQL 顺序及交付目标，展开后查看说明、配置原文、校验值及下载操作。

当前阶段、验收、结果核实和最近冻结版本 ZIP 跨页签可达；终止及撤销验收收进更多操作。窄屏将阶段操作置于内容上方，进度按需展开。远端写入前展示操作者 GitLab 身份，沿用后端状态、权限和冻结 SHA。业务契约见[发布管理详细设计](project-releases.md)。

### 创建项目抽屉与侧栏密度

创建项目保留右侧抽屉，桌面宽度以 720px 为起点，标题及底部操作固定，正文独立滚动。单列按名称、编码、初始管理员、项目摘要、项目图标、项目描述排序；编码常显创建后不可修改及格式示例。创建按钮使用“创建项目／正在创建…”。初始管理员默认选择当前用户，展示真实已选人数、姓名及用户名，通过“添加管理员”展开搜索候选，保留至少 1 人、最多 100 人及跨搜索选择；候选上限不作为总人数。项目摘要说明用途及 300 字限制。

图标默认仅显示当前预览与“更换图标”，展开后内置选项采用桌面四列等宽网格，单层按钮配线性图标，选中态明确；网格下方以轻分隔线区分“上传图片”，不重复显示第二份预览，无上传图片时不显示无效移除入口。收起不卸载上传编辑器或清理草稿。项目描述选填且默认收起，已有内容显示“已填写”，展开后编辑与预览共用内容区。折叠字段出错自动展开，描述错误返回编辑并聚焦，保留草稿、关闭保护、防重复提交及结果未知核实流程。本次创建布局不作为团队或其他编辑表单的强制模板。

侧栏菜单保持 14px 标签，主导航与关注项目最小点击高度统一为 40px、行高 20px、圆角 6px。两者共用 20px 图标占位、18px 线性图标及 8px 图文间距；关注项目的内置图标取消 32px 底板，上传图片在相同占位内呈现，折叠态居中。分组标题使用 13px，关注分组上下留白为 12px，控制台分组分隔线上方 12px、下方 8px，品牌区与导航间距 16px。尺寸按用户确认的紧凑方案执行，保留桌面缩放与键盘操作可达性；悬停与选中背景、键盘焦点仍覆盖整行。

### 项目仓库与分支配置操作

项目仓库列表移除页头说明，关联仓库按钮置于表格工具栏右侧，与批量操作并列，沿用原有管理权限。Git 分支规则的已启用状态使用成功色，未启用使用中性色，异常匹配和无效名称保留警告与危险语义。

产品分支设置与环境详情抽屉默认只读，底部固定展示关闭与编辑；点击编辑后原位切换为取消与保存，保存成功回到只读视图。产品分支的固定主干及环境的固定绑定分支在编辑态可修改，仍受权限、归档和命名规则约束；未保存保护、版本冲突及结果未知处理继续保留。

### 项目介绍的 Markdown 编辑与渲染

项目介绍保留编辑、预览、分栏三种模式，源码使用 CodeMirror，提供行号、当前行提示、自动换行及 Markdown/围栏代码语法高亮。切换模式保留编辑器实例、光标、滚动与撤销历史；中文输入、错误聚焦、权限只读及未保存保护继续有效。其他 Markdown 编辑入口暂不升级。

介绍的预览、阅读和保存冲突对照共用增强渲染：常见开发语言使用按需加载的 Shiki 高亮，浅深主题一致，未知语言回退纯文本。Mermaid 围栏默认显示图形，可切换源码并复制源码；图块独立延迟渲染、丢弃过期结果，语法错误保留源码与其他正文。图表随主题更新，默认在有限高度的缩略区域中等比完整展示，不裁切图形；挂载与字体加载后按实际 SVG 绘制边界重算视区。点击缩略图打开遮罩查看器，支持放大、缩小、滚轮缩放、拖动平移、方向键移动与复位；Esc、关闭按钮或点击遮罩关闭并恢复触发按钮焦点。缩略图与查看器只挂载一份 SVG，避免生成的图形 ID 冲突。使用严格模式并清理生成的 SVG，不允许文档覆盖渲染配置、执行 HTML 或加载远程内容。

代码、Mermaid 与表格复制使用图标按钮：成功原位显示绿色勾，2 秒后恢复，连续复制重新计时；失败显示文字反馈，不显示成功状态。表格外框圆角、内部细分隔线，复制图标与表头同一行且保留操作空间，默认复制该表格的 Markdown 源码，包含对齐、转义及行内格式。所有新依赖及语言、图表资源随前端构建发布，运行时从同源加载。

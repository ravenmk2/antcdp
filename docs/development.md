## 项目与团队开发第二批：业务接口与正式页面（2026-10-27）

新增 `internal/modules/collaboration`，通过 identity 的业务访问事务复用会话、账号锁和强制改密限制。实现项目/团队列表、详情、创建与资料编辑、直接成员角色与退出、团队项目授权、项目归档/恢复、团队解散、成员来源合并和分页搜索、可见关联项目。系统管理员创建和处理生命周期；业务管理员管理正常对象；允许零管理员/零成员，系统管理员可重新添加。编码保留大小写，编码与名称唯一冲突分别返回明确错误。资料与成员使用独立版本，成员命令无变化时不递增版本或重复审计。

成员或授权移除后，事务内重新计算访问来源；只清理已失去全部来源的快捷方式，保留其他来源仍有效的固定项，并重排序号、增加对应分组版本。归档项目仍可查看和固定。解散团队移除直接成员和项目授权，并保留团队资料、图标和审计。

正式页面提供 `/projects`、`/teams` 及详情，工作区列表限定本人参与；控制台 `/admin/projects`、`/admin/teams` 提供全部对象、无有效管理员筛选、创建与生命周期操作。项目/团队列表在用户菜单中；侧栏仅显示固定项，分组加号在悬停或键盘焦点进入时显示，触屏常显。快捷方式弹窗支持固定、取消固定与上下排序，并使用数据库版本避免覆盖其他设备的更新。表单保留失败输入并对未保存修改提供离页保护。

独立 `icon_file` 用例支持内置图标、普通图片上传与裁剪、服务端二次规范化为 256×256 PNG、草稿绑定与过期/孤立文件回收。文件保存于 `media/icons/`，与 `media/avatars/` 的校验、读取和清理范围隔离；绑定锁定新旧文件，不能让同一草稿同时绑定项目和团队。受保护图标读取先授权再判断条件缓存；参与项目可读取该项目授权团队的图标，不因此获得团队详情权限。Markdown 使用 markdown-it，禁用原始 HTML 和图片嵌入，保留常用文本格式、列表、表格及安全链接。

验证：真实 MySQL 8.0.46 HTTP 回归覆盖普通用户越权、非成员不可见、编码/名称唯一、过期版本、直接与团队来源合并、成员分页、最后成员退出与管理员恢复、快捷清理、归档只读、恢复和解散；图标覆盖真实 multipart、绑定、重复绑定拒绝、权限先于缓存判断及孤立元数据回收。浏览器在独立真实实例验证创建与详情跳转、Markdown、图标裁剪上传、固定入口与用户菜单；修复了保存过程中的路由守卫阻止成功跳转的问题。Linux 隔离容器验证安装、16 张表、项目写入、固定项及重启保持；现有运行部署未替换。

当前接口与目标设计的差异明确记录在详细设计开头：成员命令返回 204 后重新读取；目录选择器最多返回 50 项并支持搜索，尚未增加分页；成员有效集合当前在应用层合并分页，大团队规模的查询优化和业务并发压力验收尚未完成。账号删除仍以 `user.deleted` 记录清理原因，尚未补齐逐对象成员移除审计。以上不应被宣称为完整验收矩阵全部通过，也不代表 MySQL 8.4 CI 已运行。

## 本地启动

需要 `go.mod` 指定的 Go 工具链、Node.js 22.12+ 和 npm。构建脚本按锁文件安装前端依赖，执行 Vue/TypeScript 检查并构建 SPA。

```sh
bash scripts/build-web.sh
go run ./cmd/antcdp serve --listen 127.0.0.1:8080 --public-url http://localhost:8080
```

Windows PowerShell 可用 Git for Windows 的 Bash 执行第一条命令：

```powershell
& 'C:/Program Files/Git/bin/bash.exe' scripts/build-web.sh
go run ./cmd/antcdp serve --listen 127.0.0.1:8080 --public-url http://localhost:8080
```

数据目录默认是仓库根目录下被忽略的 `data/`；可用 `--data-dir` 改为其他持久化目录。`ANTCDP_PUBLIC_URL` 或 `--public-url` 应设置为浏览器实际访问的来源地址。配置缺失或为空且没有安装痕迹时进入安装欢迎页，随后填写数据库连接，检查和最终安装都要求空库。所有安装步骤成功后最后写入 `data/install.lock`；存在时跳过安装，配置或数据库异常进入维护状态。

`GET /healthz` 检查进程存活，`GET /readyz` 在未安装或正常运行时返回 200。`GET /api/v1/setup/status` 显示安装状态，响应不包含文件路径或数据库口令。安装端点的状态约束、CSRF 及请求格式见 [API 文档](api.md)。

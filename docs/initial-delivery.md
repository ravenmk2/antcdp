# AntCDP 首次交付

更新日期：2026-10-23。

本文仅记录首次迁移时的范围与验收，不约束后续功能和 UI 设计。当前实现见 [开发说明](development.md)，现行设计见 [UI 规范](ui-design.md)；下文的占位 LOGO 和功能规划属于当时状态。

AntCDP = AI Native Team Collaboration & Development Platform，中文为 AI 原生团队协作开发平台。

## 迁移与交付边界

- 从原项目提交 `8c7a099df3bd39f713dddfb8f02334a64aebf35f` 复制全部受版本控制的代码、测试、文档、数据库迁移、许可证及构建发布配置。
- 原仓库及其历史保持不动；AntCDP 使用独立仓库，将迁移和界面改造一起形成一个初始提交，不导入原提交历史。
- 不迁移原系统的数据库、账号、会话、头像、配置、主密钥或安装记录；新实例必须使用独立空数据库与数据目录。
- 延续模块化单体、Go/Gin、MySQL/sqlx/goose、Vue/TypeScript/Vite/Pinia/Element Plus，以及 SPA 和 SQL 迁移嵌入二进制的交付方式。
- 已实现功能完整保留；项目、团队、多仓库、Graph 工作流和 AI 执行仍属于后续规划。品牌中的 AI Native 不代表这些模块已经交付。

## 工程与视觉变化

- Go module 为 `github.com/ravenmk2/antcdp`，入口为 `cmd/antcdp`，二进制为 `antcdp`，前端包为 `antcdp-web`。
- 环境变量统一使用 `ANTCDP_`，浏览器偏好使用 `antcdp.*`，Cookie、CSRF 密钥派生标识、测试库前缀、容器和发布配置同步采用新名称。
- 界面采用 暖色中性布局，覆盖浅色、深色与跟随系统；安装和维护状态、登录注册、账号、首页、控制台、头像及审计共享主题。
- 语义色集中到 `web/src/shared/tokens.css`，Element Plus 浮层及功能样式映射到同一套变量。
- 外观偏好只在本机保存；页面加载前应用主题，系统模式响应操作系统变化，标签页同步偏好。禁用浏览器存储时仍能在当前页面切换。
- LOGO 暂用纯色小圆角正方形 SVG，占位资源在 `web/public/logo.svg`；最终 LOGO 另行设计。

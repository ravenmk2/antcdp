# 服务集成

服务集成管理连接、访问凭证、服务适配器及入站验证。已注册类型、认证方式、参数和能力以适配器目录及接口实现为准。SSH 主机、消息发送、模型和网络检索分别属于独立模块。

- [HTTP 装配](../../../internal/server)
- [前端功能](../../../web/src/features/integrations)
- [凭证功能](../../../web/src/features/credentials)

## 关键边界

- 连接与凭证的归属、身份和使用资格由服务端校验。引用存在不代表被授权使用。
- 身份秘密、出站凭证与入站验证秘密按用途隔离；普通资料不返回秘密。
- 远端诊断只证明实际检查到的事实。认证成功不推定业务权限，网络失败不推定操作未执行。
- 地址、DNS、TLS、重定向和响应限额由受控网络与适配器共同验证。

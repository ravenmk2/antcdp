# 智能体执行与恢复

本篇只保留跨组件的执行关系。状态枚举、消息载荷、工具参数、容量限制和错误码以[执行核心](../../../internal/agentcore/)、[平台宿主](../../../internal/modules/agents/)、[HTTP 装配](../../../internal/server/agents.go)及[流协议实现](../../../internal/server/agents_stream.go)为准。

## 输入与授权

受理输入、实际领取执行和后续客户端操作是不同授权时点。根轮次冻结本次执行所需的账号、模型、工具和资源上下文；后续配置变更不改写已经保存的运行事实。排队项及新操作重新验证当前资格。

问题回应与动作审批关联原始交互和调用摘要。回应不能扩大权限、替换原动作或复活已停止的操作。子任务继承明确的根授权与内容域。

## 持久事实与观察

输入、工具意图、唯一结果、终态和文件绑定由持久记录表达。临时模型流、浏览器状态和展示缓存不能代替这些事实，也不能反向重建原生模型历史。

流恢复按持久序号和临时流游标分别处理，校验代次、顺序和完整性；不连续历史不得拼接成完整事实。缓存可重建，不能承担授权或执行结算职责。

## 逻辑结束与物理收尾

模型输出完成、轮次逻辑结束和外部活动实际结束分别记录。浏览器断开不停止服务器执行；取消请求不等于远端已退出。

远端结果未知时保留意图、资源引用和核实依据。重启恢复不得通过重复调用来猜测原操作结果，也不能释放仍可能被使用的工作空间。工具结果只能结算一次，后续核实追加观察，不改写历史。

## 文件与跨存储事务

平台文件、工作空间和数据库没有分布式事务。上传、复制、绑定和删除分别验证引用、权限和内容完整性；失败留下可核实状态。会话生命周期不能隐式删除正式成果。
